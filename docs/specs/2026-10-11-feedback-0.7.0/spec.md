# 0.7.0을 써 보고 고칠 것

## 목표와 범위

사용자가 2026-10-11에 0.7.0을 써 보고 일곱 가지를 알렸어요. 인터뷰로 정한 것을 명세와 [극장판 ADR](../../adr/0017-movies-by-place-and-anissia-link.md)에 적고 티켓으로 나눴어요.

| 피드백 | 티켓 |
| --- | --- |
| 속편의 저장 폴더 제안에 제목의 `S2`가 남아 `Nige Jouzu no Wakagimi S2/Season 01`이 됨 | 0137 |
| 작품과 시즌을 따로 받고, 시즌을 더 잘 제안함(1기·2기와 1쿨·2쿨이 작품마다 다름) | 0137 |
| Anissia에 이은 작품은 한글 제목으로 보여줌 | 0138 |
| 극장판만 있는 작품 지원 | 0139 |
| 시즌이 있는 작품의 극장판 지원 | 0140 |
| 상단바 제거, 화면 모드는 설정으로 | 0142 |
| Anissia 편성의 종영·결방 같은 상태 표시 | 0141 |

## 진행 순서

이 티켓들은 [리팩터링 뒤의 명세 차이 수정](../2026-09-30-web-redesign/spec.md#리팩터링-뒤의-명세-차이-수정)의 대기 티켓과 목표 6보다 먼저 해요(사용자 결정, 2026-10-11). 0.7.0을 쓰며 바로 걸리는 것들이기 때문이에요.
2026-10-21에 [구조 가볍게 하기](../2026-09-30-web-redesign/spec.md#구조-가볍게-하기)를 이 묶음의 남은 티켓(0140·0143)보다 먼저 하기로 했고, 2026-10-22에 마쳤어요.

## 완료 기준

이 묶음의 결과는 [0143](0143-deploy-feedback-fixes.md)이 새 릴리스를 서버에 올려 확인하고, 피드백 일곱 가지가 모두 다뤄졌는지 이 문서에 적어요. 그 완료 기준의 상자는 0143에 있어요.
