# 0143 0.7.0 피드백의 수정을 배포하고 서버에서 확인해요

- 상태: 진행 중
- 출처: [0.7.0을 써 보고 고칠 것](spec.md), [readme의 Releasing](../../../readme.md#releasing)
- 막는 티켓: [0137](0137-work-and-season-folder-input.md), [0138](0138-work-title-from-anissia.md), [0139](0139-movie-only-works.md), [0140](0140-movies-in-season-00.md), [0141](0141-anissia-status-shown.md), [0142](0142-phone-top-bar-and-theme-setting.md)

## 작업

0137–0142를 담은 릴리스를 실제 서버(j4105)에 올리고, 사용자가 0.7.0에서 겪은 것이 서버에서 고쳐졌는지 봐요.
릴리스 태그, 이미지 게시, 배포는 사용자가 승인한 뒤에 해요.
0137–0139·0141·0142의 확인은 구조를 가볍게 한 릴리스를 올리는 [lighter-structure/0162](../../archive/tickets/lighter-structure/0162-deploy-lighter-structure.md)에서 함께 해요(사용자 결정, 2026-10-22). 0140에 기대는 Re Zero `Season 00` 극장판의 확인은 0140을 올릴 때 해요.

- 마이그레이션이 있으면 올리기 전에 서버 DB의 새 복사본으로 확인해요([readme의 Releasing](../../../readme.md#releasing)).
- 서버에서는 이미 있는 데이터로 볼 수 있는 것부터 봐요.
  - 라이브러리 격자와 작품 상세의 작품명이 한글이에요. 손으로 이은 `All Works Maid`도 그래요.
  - `Chou Kaguya-hime!`가 `본편` 한 줄로 보여요.
  - Re Zero의 `Season 00` 극장판을 Anissia에 이으면 `극장판`과 제목이 보여요. 자막 후보가 있으면 받아 봐요.
  - 휴대폰에 상단바가 없고, 설정에서 화면 모드를 바꿀 수 있어요.
  - 구독 카드에 Anissia 상태와 종영일이 보여요.
- 저장 폴더 제안은 속편을 실제로 구독할 때 보여요. 다음 분기를 기다리지 않고, 서버 DB 복사본에서 구독 화면을 열어 지금 서버에 있는 속편 제목으로 제안을 봐요. 구독은 만들지 않아요.
- `이번 주 종영`은 종영일이 든 주가 와야 보여요. 그 주를 기다리지 않고, 테스트와 서버 DB 복사본의 날짜를 바꾼 확인으로 대신해요(사용자 결정, 2026-10-22).

## 완료 기준

- [ ] 새 릴리스가 서버에서 돌고, 위의 서버 확인을 날짜, 버전과 함께 이 티켓의 결과에 적어요. 보지 못한 것은 까닭과 함께 적어요.
- [ ] 0137–0142가 고친 검증 표의 행에 서버에서 본 것을 더해요.
- [ ] [0.7.0을 써 보고 고칠 것](spec.md)의 티켓이 모두 끝나면, 피드백 일곱 가지가 모두 다뤄졌는지 그 절에 적어요.

## 결과

### 0.8.0 배포에서 본 것

2026-10-22에 [lighter-structure/0162](../../archive/tickets/lighter-structure/0162-deploy-lighter-structure.md)가 0.8.0을 서버에 올린 뒤, 서버 화면을 이 PC의 내장 브라우저로 열어 읽기만 했어요. 저장 폴더 제안과 `이번 주 종영`은 작업에 적은 대로 서버 DB의 새 복사본으로 띄운 개발 환경에서 봤어요. 그 개발 환경은 0.8.0과 같은 코드로 빌드한 이미지예요.

- 작품명: 라이브러리 작품 92개 가운데 Anissia에 이은 13개가 한글 작품명이었어요. 손으로 이은 `All Works Maid`는 격자와 상세 머리 모두 `히로인? 성녀? 아니요, 올 워크스 메이드 입니다(자랑)!`이었어요.
- `Chou Kaguya-hime!`: 상세의 회차 목록이 `본편` 한 줄(영상 보유, 자막 보유)이었고, 휴대폰 크기의 격자도 `영상 본편`·`자막 본편`이었어요.
- 휴대폰 화면(375px): 상단바 없이 화면 제목부터 시작했고 아래 메뉴가 있었어요. 설정의 `화면` 묶음에 `화면 모드`(`시스템`)가 있었어요. 서버 화면을 이 PC의 내장 브라우저로만 읽어서, 실제 휴대폰의 위쪽 안전 영역과 실제 기기에서 화면 모드를 바꾸는 것은 보지 못했어요.
- 구독 카드: 이번 분기 구독 다섯 개가 모두 `방영 중`을 보였어요. 다섯 모두 Anissia에 종영일이 없어서, 카드의 종영일은 서버에서 볼 수 없었어요.
- 저장 폴더 제안: 서버 DB 복사본의 속편 규칙 8개의 릴리스 제목으로 제안 API에 물었어요. 시즌 표시가 있는 5개(`Clevatess S2`, `Otome Game Sekai wa Mob ni Kibishii Sekai desu S2`, `Nige Jouzu no Wakagimi S2`, `Hell Mode S2`, `Mushoku Tensei S3`)는 모두 사용자가 그 규칙에 적은 폴더로 제안됐어요. 나머지 셋은 그 시즌을 받은 뒤에 물어서 다음 시즌이 제안됐어요. `Re Zero kara Hajimeru Isekai Seikatsu`와 `Tensei Shitara Slime Datta Ken`은 마지막 시즌(04)의 AniList 항목이 9월에 끝나 `Season 05`였어요. 구독의 시작일 2026-07-05를 준 `Seihantai na Kimi to Boku`는 시즌 1·2가 모두 Anissia에 이어져 있지 않아 `Season 03`이었어요. 구독은 만들지 않았어요.
- `이번 주 종영`: 그 주를 기다리지 않고, 개발 환경의 날짜 바꾼 확인과 [0141](0141-anissia-status-shown.md)의 테스트로 대신하기로 했어요(사용자 결정, 2026-10-22). 개발 환경에서 `FX 전사 쿠루미`의 종영일을 그날(목요일)로 바꾸자 목요일 카드에 `이번 주 종영`이, 구독 카드에 `10월 22일 종영 예정`이 나왔어요. 바꾼 값은 되돌렸어요.

0137–0139·0141·0142가 고친 검증 표의 행에 위에서 본 것을 더했어요. 남은 것은 [0140](0140-movies-in-season-00.md)에 기대는 Re Zero `Season 00` 극장판의 확인이고, 0140을 올릴 때 봐요.
