# 0028 자막 제작자를 이름만 보여줘요

- 상태: 완료
- 출처: [머리와 시즌](../../../specs/library.md#머리와-시즌)의 제작자 표시
- 막는 티켓: 없음

## 작업

구독 제작자를 `에루샤 따라 받기` 대신 `에루샤`로 보여줘요(사용자 결정, 2026-10-02).
`자막 제작자`·`자막` 같은 이름표 옆의 요약과, 제작자를 고르는 목록(구독 추가의 자막 단계, `제작자 변경`)의 선택지 모두 같아요.
이름표나 목록 제목(`자막 제작자를 골라요` 등)이 이미 자막 제작자라고 말하기 때문이에요.
`제작자 미정`·`받지 않음`은 그대로예요.

## 완료 기준

| 화면 | 기대 결과 |
| --- | --- |
| 작품 상세 머리, 규칙 상세의 자막 제작자 줄, 구독 탭의 구독 카드, 구독 추가의 확인 단계, 기존 YAML 가져오기 결과 | 제작자를 따라 받는 구독은 이름만 보여요. |
| 구독 추가의 자막 단계와 `제작자 변경` 목록 | 선택지는 `에루샤`·`제작자 미정`(구독 추가에는 `받지 않음`도)이고, 목록 제목이 자막 제작자를 고른다고 알려요. |
| `받지 않음` 구독(제작자를 남겨 둔 상태) | `받지 않음`이 보이고, 남겨 둔 제작자 이름으로 바뀌지 않아요. |

## 결과

- 표시 함수 `subtitleChoice`(`web/src/screens/collect/subs/format.ts`)가 `follow`일 때 제작자 이름만 돌려줘요. 구독 탭의 구독 카드, 규칙 상세의 자막 제작자 줄, 작품 상세 머리, 구독 추가의 확인 단계가 이 함수를 써서 함께 바뀌었어요.
- 고르는 목록: 구독 추가의 자막 단계(`PickSubtitles.tsx`)와 `제작자 변경` 목록(`CreatorPicker.tsx`)의 선택지가 이름만이에요. 목록 제목은 그대로 `자막을 어떻게 받을지 골라요`·`자막 제작자를 골라요`이고, 자막 단계의 선택지 아래 문장(`에루샤가 새 회차 자막을 올리면 자동으로 받아요.`)도 그대로예요.
- 기존 YAML 가져오기 결과(`ResultStep.tsx`)의 구독 줄에는 이름표가 없어서 `시험 작품 · 자막 에루샤`처럼 `자막`을 붙였어요. 원래 `·`와 제작자 사이에 빠져 있던 띄어쓰기도 함께 고쳤어요. 이 문구는 명세에 정해진 말이 아니라 구현하며 정했어요.

### 검증한 것

- `tsc -b`가 통과했고, `web/src`에 `따라 받기`가 남아 있지 않아요(`grep`).
- 브라우저(로컬 `trss-web`, 임시 DB, 가짜 Anissia, 데스크톱 너비, 2026-10-02): 주석에 `자막: 에루샤`와 Anissia 주소가 있는 기존 YAML을 가져와 아래를 차례로 봤어요.
  - 가져오기 결과: `시험 작품 · 자막 에루샤`
  - 구독 카드: `자막 에루샤`, 규칙 상세: `자막 제작자 에루샤`
  - `제작자 변경` 목록: `에루샤`·`하느`·`제작자 미정`
  - 구독 추가(두 번째 작품, 채널 기록 한 줄을 DB에 넣어 릴리스 제목 단계를 지남)의 자막 단계: `에루샤`·`하느`·`제작자 미정`·`받지 않음`, 확인 단계: `자막 에루샤`
  - 작품 상세 머리(worker를 한 번 돌려 작품을 발견하고, 구독의 시즌 연결은 DB에 직접 넣음): `자막 제작자 에루샤`
  - 규칙 상세에서 `자막 받기`를 끈 뒤: 규칙 상세와 구독 카드 모두 `받지 않음`

### 검증하지 못한 것

- 휴대폰 너비는 보지 않았어요. 줄이 짧아지기만 한 변경이에요.
