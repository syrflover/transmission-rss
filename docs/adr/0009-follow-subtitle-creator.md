# 구독 제작자의 새 회차 자막은 자동으로 받아요

방영작을 구독할 때 따라갈 자막 제작자를 정하고, 그 제작자의 아직 받지 않은 회차 자막은 후보가 나타나면 사용자 선택 없이 받아요.
처음 명세는 자막 후보의 자동 선택을 범위 밖에 두었지만, 사용자는 이미 구독 시점에 제작자를 정해 채널 설정의 주석에 적어 왔어요.
매 회차 같은 제작자를 다시 고르는 일은 새 정보가 없는 수작업이라 이 결정을 다시 열었어요.

자동 수신은 구독 제작자의 받지 않은 회차에 한정해요.
이미 받은 회차의 자막 수정본 교체와 다른 제작자의 자막은 지금처럼 사용자가 고르고 교체를 승인해요.
필요한 CAPTCHA는 자동으로 풀지 않고 할 일로 올라와요.
구독 제작자가 없는 작품에 자막 후보가 처음 나타나면 제작자를 정하라는 `자막 구독` 할 일을 만들어요.
구독 제작자가 오래 올리지 않을 때 다른 후보를 자동으로 받거나 할 일로 올리는 안은 기간 규칙이 새로 필요해 고르지 않았어요.
제작자가 방영 중에 바뀌면 사용자가 구독을 고쳐야 하는 비용이 있어요.

이 기록은 선택한 방향이며 아직 구현된 동작은 아니에요.
선택 배경은 [웹 재설계 주제 문서](../brainstorm/web-redesign.md#자막-제작자-자동-수신)에, 현재 요구는 [자막 명세](../specs/subtitles.md#구독-제작자-자동-수신)에 있어요.
