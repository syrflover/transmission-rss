# 작품 폴더에는 자막과 폰트만 두고 나머지는 앱 데이터 폴더에 둬요

작품 폴더에는 숨김 폴더 `.trss/` 하나만 두고, 그 안에는 보관 자막과 그 자막이 쓰는 폰트만 둬요.
표지 이미지, 자막 묶음의 설명·라이선스 같은 첨부, 그 밖의 메타데이터는 SQLite DB 옆의 앱 데이터 폴더에 둬요.
이 기록은 [보관본과 적용본](0003-stored-and-applied-subtitles.md)의 `.trss-subtitles/` 안 배치와 공유 폰트 영역, [표지](0007-anilist-work-artwork.md)의 `.trss-artwork/`, [앱 설정 교환](0001-app-managed-download-rules.md)의 `.trss-subtitles/` 이동 설명을 대체해요.
보관본과 적용본을 나누고 적용본을 독립 복사본으로 만든다는 0003의 결정은 그대로예요.

자막은 `.trss/subtitles/제작자/원래 파일명`처럼 제작자 폴더 아래에 평평하게 두고, 같은 이름·다른 내용의 파일은 `원래 파일명 (2)`처럼 번호를 붙여요.
어느 회차의 몇 번째 수정본인지는 DB가 기록해요.
자막 수정본은 대개 같은 게시물에서 파일만 바뀌어 올라와 원래 파일명이 같은 경우가 많고, 사용자가 폴더를 열었을 때 제작자와 원래 이름으로 찾을 수 있는 쪽을 골랐어요.
시즌·회차·수정본 폴더를 두던 배치보다 폴더만 보고 수정본의 순서를 알기 어려운 비용이 있어요.

폰트는 그 폰트를 쓰는 자막과 한 묶음으로 다뤄 같은 제작자 폴더에 자막과 나란히 둬요.
같은 제작자 폴더 안에서 이름과 내용이 같은 폰트는 한 번만, 이름만 같은 폰트는 번호를 붙여 둬요.
자막을 정리하면 다른 자막이 쓰지 않는 폰트도 함께 정리해요.
작품 전체에서 폰트를 한 번만 두던 공유 영역보다, 두 제작자가 같은 폰트를 쓰면 두 벌을 두는 비용을 받아들였어요.

재생기가 쓰는 것은 영상 옆 적용본뿐이고 표지는 DB에서 작품 ID로 연결되므로, 작품 폴더를 옮겨도 표지 연결이 끊기지 않아요.
대신 작품 폴더만 다른 서버로 복사하면 사용자가 고른 표지와 첨부는 따라가지 않으며, 앱 데이터 폴더는 DB와 함께 백업해야 해요.

이 기록은 선택한 방향이며 아직 구현된 동작은 아니에요.
선택 배경은 [웹 재설계 주제 문서](../brainstorm/web-redesign.md#자막-보관-위치와-수정본)에, 현재 요구는 [자막 명세](../specs/subtitles.md#보관본과-적용본)와 [표지](../specs/library.md#작품-표지)에 있어요.
