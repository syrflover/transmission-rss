# 다운로드 규칙을 앱에서 관리해요

현재 trss는 `CHANNELS_CONFIG_URL`이 가리키는 외부 YAML을 실행마다 읽어요.
웹 GUI에서 작품과 다운로드 규칙을 편집·저장해 바로 사용하는 경험을 위해, 앞으로 실행의 기준은 앱이 관리하는 설정으로 전환하기로 했어요.
기존 YAML 가져오기와 설정 내보내기를 제공해 기존 설정을 옮기고 파일로 보관할 수 있게 해요.

외부 YAML을 계속 기준으로 두고 웹에서는 편집본만 내보내는 대안은 파일·Git 중심 관리 흐름을 유지하지만, 웹 편집 후 외부 파일에 별도로 반영해야 해요.
이 추가 단계를 없애는 앱 중심 관리 방식을 선택했으므로, 외부 YAML 변경을 계속 자동 반영하는 기존 동작은 유지하지 않아요.

이 기록은 선택한 방향이며 아직 구현된 동작은 아니에요.
저장 형식, 가져오기 시 충돌 처리, 내보내기 호환 범위는 아직 정하지 않았어요.
제품 범위와 관련 근거는 [웹 GUI와 자막 수작업 개선](../brainstorm/web-gui-subtitles.md)에 있어요.
