# 높은 영상 수정본은 자동으로 받아 이전 영상을 대체해요

폴더에 있는 회차 영상보다 높은 수정본(`14v2` 등)이 나오면, 방영 중 RSS와 지난 회차 검색 모두 같은 규칙으로 수정본을 받아 이전 영상을 대체해요.
새 영상은 같은 회차 이름을 쓰므로 옆의 적용본 자막은 그대로 이어지고, 작품 상세의 해당 회차 줄에 영상이 수정본으로 바뀌었다는 사실을 조용히 남겨요.

대체한 이전 영상은 수정본의 수신과 확인이 끝난 뒤 바로 삭제해요.
작품 폴더 안에 남기면 재생기가 같은 회차를 두 번 보여줄 수 있고, 숨김 폴더로 옮기는 안은 [작품 폴더에 자막과 폰트만 둔다는 결정](0008-trss-folder-and-app-data-files.md)을 넓혀야 했어요.
수정본에서 자막 타이밍이 어긋나도 이전 영상으로 되돌릴 수 없는 비용을 받아들였어요.

trss는 받은 영상의 이름을 `trname`으로 바꾸므로 파일 이름으로는 원래 수정본을 알 수 없어요.
trss가 받은 영상은 수집 이력의 원래 릴리스 이름과 파일의 CRC32로 버전을 알고, 버전을 모르는 기존 영상은 파일 내용의 CRC32를 릴리스 이름 끝의 값과 대조해요.
구버전과 같으면 대체하고, 최신 수정본과 같으면 건너뛰며, 어느 것과도 다르면 버전 미상으로 두고 자동으로 대체하지 않아요.
2026-09-29에 SubsPlease와 Erai-raws 표본 하나씩에서 이름의 값이 파일의 CRC32와 같았지만, 모든 릴리스가 이 관례를 지킨다는 보장은 아니에요.

이 결정은 기존 명세가 보류한 중복 영상 선택 가운데 같은 릴리스의 수정본만 정해요.
다른 그룹의 같은 회차처럼 나머지 중복은 계속 보류해요.

이 기록은 선택한 방향이에요.
방영 중 RSS의 대체는 [티켓 0025](../archive/tickets/2-work-discovery-and-subscriptions/0025-replace-video-revisions.md)로 구현했고, 지난 회차 검색에서 받는 수정본은 아직이에요.
선택 배경은 [웹 재설계 주제 문서](../brainstorm/web-redesign.md#영상-수정본의-대체)에, 현재 요구는 [RSS 수집 명세](../specs/collection.md#영상-수정본의-대체)에 있어요.
