# 도메인 용어

**작품(Work)**
: 로컬에서 영상과 자막을 시즌·회차로 묶어 관리하는 대상이에요.
다운로드에 사용한 RSS 채널이나 자막 출처와 별도로 식별해요.

**시즌(Season)**
: 한 작품 안에서 에피소드를 구분해 묶는 단위예요.
봄·여름 같은 방영 분기나 외부 서비스의 개별 작품 항목과는 구분해요.

**에피소드(Episode)**
: 작품의 시즌 안에서 구분해 관리하는 한 회차예요.
파일 자체가 아니라 파일이 대응되는 단위이며, 해당 회차의 파일이나 자막을 갖고 있는지와는 별개예요.

**RSS 채널(RSS Channel)**
: 영상 다운로드 후보를 제공하는 RSS 피드와 그 수집·다운로드 설정의 단위예요.
작품을 분류하는 상위 범주가 아니며, 자막의 게시 경로를 나타내는 자막 출처 연결과 구분해요.

**다운로드 규칙(Download Rule)**
: 특정 RSS 채널의 항목에 적용하는 일치 조건과 다운로드·영상 이름 정리 설정이에요.
각 규칙은 RSS 채널 하나에 연결되며, 같은 채널에서는 평가 순서상 먼저 일치한 규칙이 적용돼요.

**자막 출처 연결(Subtitle Source Binding)**
: 로컬 작품·시즌에서 회차 해석을 함께 적용하기로 확인한 제작자·게시 경로 등의 출처 맥락이에요.
앱의 안정적인 ID로 식별하며, 웹사이트 주소나 제작자 표시명 자체를 전역 고유 ID로 취급하지 않아요.
한 웹사이트의 모든 자막이 같은 회차 체계를 쓴다는 뜻은 아니에요.

**회차 대응(Episode Mapping)**
: 로컬 작품·시즌의 영상 회차와 특정 자막 출처의 회차를 연결하는 관계예요.
번호가 같다는 뜻으로 한정하지 않으며, 자막의 누적 13화와 영상의 시즌 2 1화처럼 서로 다른 번호를 연결할 수 있어요.

**영상 대기(Awaiting Video)**
: 선택한 자막 파일은 받았지만 연결된 폴더에 배치 가능한 영상이 아직 준비되지 않은 상태예요.
영상 파일이 없거나, 다운로드 중임이 확인돼 아직 적용을 기다리는 경우를 포함해요.
사이트 인증 때문에 자막 파일 수신을 진행하지 못하는 인증 대기와 구분해요.

**자막 묶음(Subtitle Package)**
: 한 다운로드 후보에서 받거나 복원한 자막·폰트 등 연관 파일의 집합이에요.
한 회차의 파일 하나로 한정하지 않으며, 묶음에 들어 있다는 사실만으로 모든 파일이 배치 대상으로 선택되는 것은 아니에요.

**배치 계획(Placement Plan)**
: 자막 묶음의 파일을 어떤 영상에 연결하고 어느 경로에 추가·교체·유지할지 정리한 결과예요.
실제 파일 반영이나 사용자 승인 완료와 구분해요.

**보관본(Stored Subtitle)**
: 작품의 자막 보관 영역에 남겨둔 특정 제작자·회차·언어·용도·형식·수정본의 자막과 그 자막이 참조하는 보조 자산이에요.
현재 영상 옆에 적용돼 있는지와는 별개이며, 여러 보관본이 내용이 같은 폰트 하나를 함께 참조할 수 있어요.

**적용본(Applied Subtitle)**
: 선택한 보관본을 복사해 trss가 영상 옆에 같은 파일명 줄기로 배치한 독립된 자막 파일이에요.
재생기에 노출할 파일이라는 뜻이며, 재생기가 실제로 그 트랙을 선택했다는 의미는 아니에요.
