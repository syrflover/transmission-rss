# 0137 저장 폴더를 작품 칸과 시즌 칸으로 받고 시즌을 제안해요

- 상태: 대기
- 출처: [방영작 구독](../specs/collection.md#방영작-구독)의 저장 폴더(2026-10-11에 더한 요구), 0.7.0을 써 본 사용자 피드백(2026-10-11)
- 막는 티켓: 없음

## 작업

0.7.0의 구독 화면은 저장 폴더를 경로 한 칸으로 받고, 고른 릴리스 제목에서 `<작품>/Season 01`을 제안해요(`trss-collect` `subscriptions/mod.rs`의 `folder_suggestion`, `web/src/screens/collect/subs/add/PickFolder.tsx`). 그래서 `Nige Jouzu no Wakagimi S2`를 구독할 때 `Nige Jouzu no Wakagimi S2/Season 01`이 제안됐고, 사용자가 손으로 `Nige Jouzu no Wakagimi/Season 02`로 고쳤어요.
2026-10-10에 서버에서 읽은 속편 규칙 8개도 모두 사용자가 시즌을 손으로 고쳤어요. 5개는 제목에 `S2`·`S3` 표시가 있었고, 3개는 앞 시즌에 이어 센 번호라 회차 변환을 썼어요(데이터는 `dev/local/measure/feedback-0.7.0/`).

[방영작 구독](../specs/collection.md#방영작-구독)의 저장 폴더 요구대로 만들어요. 사용자가 정한 것은 다음과 같아요(2026-10-11).

- 저장 폴더는 작품 칸과 시즌 칸으로 받고, 늘 `<작품>/Season NN`이에요. 작품 칸에서는 라이브러리 작품을 고르거나 새 이름을 써요.
- 시즌 표시가 없으면 AniList가 나눈 시즌을 따라 제안해요. 릴리스 번호가 앞 시즌에 이어지는지로는 정하지 않아요.
- 구독 화면, 규칙 추가 화면, 규칙 편집 화면이 같은 두 칸을 쓰고, 규칙 화면에만 경로를 직접 적는 길을 둬요.

명세에 리드가 적은 것도 있어요. 사용자가 다르게 정하면 명세와 함께 고쳐요.

- 읽는 시즌 표시는 `S2`·`Season 2`·`2nd Season`·`2기`·`第2期`예요. `Part 2`·`2쿨`은 시즌으로 읽지 않아요.
- 이 방영을 AniList 항목이 담는지는 Anissia 방영 시작일이 그 항목의 방영 기간 안인지로 봐요.

다음은 이 티켓에서 정해요.

- **작품 칸이 라이브러리 작품을 찾는 방법.** 시즌 표시를 뺀 이름을 폴더 이름과 견줄 때 대소문자, 공백, 기호를 어떻게 맞출지 정해요. 표지 자동 판정의 제목 정규화(`trss-anilist` `title.rs`)를 쓸 수 있는지 먼저 봐요.
- **시즌 칸 제안의 위치.** 제안을 서버(trss-collect)에서 만들지 정해요. AniList 항목과 라이브러리 시즌을 읽어야 하므로 서버 쪽이 자연스러워요.
- **보관 폴더 작품.** 작품 칸에서 고른 작품이 보관 폴더에 있으면 지금처럼 옮긴다는 안내가 떠야 해요(`ArchivedWorkNotice`).

## 완료 기준

- 구독 화면, 규칙 추가 화면, 규칙 편집 화면이 작품 칸과 시즌 칸으로 저장 폴더를 받아요. 규칙 화면에는 경로를 직접 적는 길이 있고, 꼴이 다른 기존 폴더는 그 길로 열려요.
- 제안을 규칙을 가진 크레이트의 테스트가 확인해요. 다음 경우를 겨눠요.
  - `Nige Jouzu no Wakagimi S2`는 라이브러리 작품 `Nige Jouzu no Wakagimi`와 시즌 2로 제안돼요.
  - `2nd Season`과 `2기`도 같은 결과예요. `Part 2`는 시즌 표시로 읽지 않아요.
  - 앞 시즌의 AniList 항목이 이 방영을 담지 않으면 다음 시즌이에요. 23화로 끝나고 24화로 시작하는 속편도 그래요.
  - 앞 시즌의 AniList 항목이 이 방영을 담으면(2쿨을 한 시즌으로 두는 작품) 같은 시즌이에요.
  - AniList 항목이 없으면 다음 시즌이에요.
  - 라이브러리에 없는 작품은 시즌 1이에요.
- 제목 대기 구독은 작품 칸이 비고, 라이브러리 작품을 고르면 시즌 칸이 채워져요.
- [수집 명세의 검증 표](../specs/collection.md#검증-표)에서 저장 폴더 행을 고쳐요.
