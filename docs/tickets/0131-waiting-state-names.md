# 0131 사람을 기다리는 상태의 이름을 화면마다 맞춰요

- 상태: 대기
- 출처: [할 일](../specs/jobs.md#할-일)의 "한 상태는 할 일 종류·회차 배지·기록에서 같은 이름을 써요", [0110](0110-job-line-tests.md)에서 검증 표를 쓰며 찾은 차이(2026-10-09)
- 막는 티켓: 없음

## 작업

2026-10-09에 사람의 결정을 기다리는 두 상태가 화면마다 다른 이름으로 보였어요.

| 상태 | 할 일 종류, 작업 배지, 작품 회차 줄, 자막 후보의 작업 상태 | 작업 상세 `회차별 결과`의 낱말 | `회차별 결과`의 묶음 제목 |
| --- | --- | --- | --- |
| 교체 승인 | `교체 승인` | `교체 승인 대기` | `교체 승인 대기` |
| 회차 확인 | `회차 확인 필요` | `회차 확인 필요` | `확인 필요` |

[작업과 인증 명세](../specs/jobs.md#할-일)는 한 상태에 한 이름을 쓰고 예전의 `교체 승인 대기`는 쓰지 않는다고 적어요. `회차별 결과`의 `교체 승인 대기`는 [0068](../archive/tickets/4-store-apply-and-replace/0068-replacement-approval.md)(2026-10-05)에서 들어왔어요.

사용자는 두 상태의 이름을 `교체 승인 대기`와 `회차 확인 필요`로 정했어요(사용자 결정, 2026-10-09).

- 할 일 종류, 작업 배지(`badges.tsx`), 작품 회차 줄의 칸(`EpisodeList.tsx`), 자막 후보의 작업 상태(`candidates.ts`)가 `교체 승인` 대신 `교체 승인 대기`를 써요.
- `회차별 결과`(`JobResults.tsx`)의 묶음 제목 `확인 필요`는 `회차 확인 필요`예요.
- 작업 단계의 `교체 승인`은 상태가 아니라 단계의 이름이라 그대로 둬요. `게시물 열기`·`받기`·`적용`처럼 하는 일을 가리켜요.
- 명세의 그 상태 이름과 "예전의 `교체 승인 대기`는 쓰지 않는다"는 문장을 고쳐요. 작업과 인증 명세, 자막 명세, 라이브러리 명세에 `교체 승인`이 상태 이름으로 나와요.

## 완료 기준

- 위의 화면이 두 상태를 각각 한 이름으로 보여줘요. 화면 테스트가 바뀐 이름을 확인해요.
- 명세에서 두 상태의 이름이 화면과 같아요.
