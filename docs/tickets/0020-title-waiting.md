# 0020 첫 화 전에 구독하고 제목 후보로 규칙을 완성해요

- 상태: 대기
- 출처: [방영작 구독](../specs/collection.md#방영작-구독)(제목 대기·제목 후보), [수집 화면](../specs/collection.md#수집-화면)(구독 탭, 상태 배너), [할 일](../specs/jobs.md#할-일)(`제목 후보`), [채널과 규칙 필드](../specs/settings.md#채널과-규칙-필드)(`match: null`)
- 막는 티켓: [0018](0018-subscribe-from-schedule.md)

## 작업

첫 화가 아직 채널에 없는 작품을 `제목 대기`로 구독하고, 새 작품 제목이 수집 이력에 처음 나타나면 `제목 후보`로 알려 사용자가 고르면 규칙이 완성돼요.

- 제목 대기 구독은 일치 문구가 `null`인 규칙이에요. 저장소와 평가는 이미 `null`을 어떤 항목에도 맞지 않는 규칙으로 다뤄요. 0018의 구독 흐름에서 릴리스 제목 단계에 `아직 첫 화 전이에요`를 둬서 만들어요. 저장 폴더는 구독할 때 정하되 릴리스 제목이 없어 제안 없이 비어 있고, 후보를 받아들일 때 그 제목에서 만든 폴더로 바꿀 수 있게 보여줘요.
- 제목 후보: 제목 대기 구독이 있는 채널의 수집 이력에 처음 나타난 작품 제목(규칙에 맞지 않은 `no_match` 항목의 작품 부분)이에요. Anissia 작품과 새 제목의 연결은 제안일 뿐이며 어느 구독의 후보인지 단정하지 않아요. 후보는 처음 나타난 제목 단위로 하나로 모아요.
- 후보 고르기: 구독 하나를 골라 일치 문구를 정하면 규칙이 완성되고, 이미 기록된 그 작품의 지난 항목 미리보기에서 확인한 것만 받아요(0018과 같은 미리보기·받기). `거절`한 후보는 다시 나타나지 않고 구독은 제목 대기 그대로예요. 기록 탭의 `no_match` 항목에서도 제목 대기 구독에 바로 잇는 동작을 보여줘요.
- 구독 탭: 제목 후보(차분한 파랑 강조)를 맨 위에, 다음 분기의 제목 대기 구독을 그 아래에 둬요. 다음 분기는 Anissia `신작`(8)에서 와요. 규칙 상세의 제목 대기·제목 후보 상태 배너는 까닭과 다음 결과를 문장으로 알려요.
- 할 일: `제목 후보`는 `제안` 무리이고 메뉴 배지에 세지 않아요. [할 일 화면](../specs/jobs.md#할-일-화면)은 목표 3에서 생기므로, 이 티켓은 할 일 목록이 읽을 제목 후보의 원천(생기고 사라지는 조건)을 두고, 할 일 화면이 생길 때 그 제안 줄이 이것을 읽어요.

## 완료 기준

| 입력·상태 | 기대 결과 |
| --- | --- |
| 첫 화 전 작품을 `아직 첫 화 전이에요`로 구독 | `match: null`의 제목 대기 규칙이 생기고 아무것도 받지 않아요. 구독 탭 다음 분기 묶음에 보여요. |
| 제목 대기 구독이 있는 채널에 처음 보는 `[SubsPlease] New Work - 01 (1080p)`가 나타남 | `New Work`이 제목 후보로 구독 탭과 할 일 원천에 하나 생겨요. 2화가 나타나도 후보는 하나예요. 메뉴 배지는 늘지 않아요. |
| 제목 대기 구독이 없는 동안 나타난 새 제목 | 제목 후보가 생기지 않아요. |
| 후보를 한 구독에 고르고 미리보기에서 `[Batch]`를 빼고 확인 | 규칙의 일치 문구가 정해지고, 확인한 회차만 Transmission에 추가돼요. 후보는 사라져요. |
| 후보를 `거절` | 후보가 사라지고 다시 나타나지 않으며, 구독은 제목 대기 그대로예요. |
| 기록 탭의 `no_match` 줄 | 제목 대기 구독이 있으면 그 줄에 잇는 동작이 바로 보이고, 없으면 보이지 않아요. |
| 이미 다른 규칙이 받은 제목 | 제목 후보가 되지 않아요. |
| 휴대폰 너비 | 구독 탭의 후보 줄과 미리보기에 가로 스크롤이 없어요. |
