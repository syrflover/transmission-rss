# 0028 자막 제작자를 이름만 보여줘요

- 상태: 대기
- 출처: [머리와 시즌](../specs/library.md#머리와-시즌)의 제작자 표시
- 막는 티켓: 없음

## 작업

구독 제작자를 `에루샤 따라 받기` 대신 `에루샤`로 보여줘요(사용자 결정, 2026-10-02).
`자막 제작자`·`자막` 같은 이름표 옆의 요약과, 제작자를 고르는 목록(구독 추가의 자막 단계, `제작자 변경`)의 선택지 모두 같아요.
이름표나 목록 제목(`자막 제작자를 골라요` 등)이 이미 자막 제작자라고 말하기 때문이에요.
`제작자 미정`·`받지 않음`은 그대로예요.

## 완료 기준

| 화면 | 기대 결과 |
| --- | --- |
| 작품 상세 머리, 규칙 상세의 자막 제작자 줄, 구독 탭의 구독 카드, 구독 추가의 확인 단계, 기존 YAML 가져오기 결과 | 제작자를 따라 받는 구독은 이름만 보여요. |
| 구독 추가의 자막 단계와 `제작자 변경` 목록 | 선택지는 `에루샤`·`제작자 미정`(구독 추가에는 `받지 않음`도)이고, 목록 제목이 자막 제작자를 고른다고 알려요. |
| `받지 않음` 구독(제작자를 남겨 둔 상태) | `받지 않음`이 보이고, 남겨 둔 제작자 이름으로 바뀌지 않아요. |
