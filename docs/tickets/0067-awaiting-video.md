# 0067 영상이 없는 회차의 자막을 영상이 들어오면 적용해요

- 상태: 대기
- 출처: [영상 대기](../specs/subtitles.md#영상-대기), [할 일과 회차 목록](../specs/library.md#할-일과-회차-목록), [할 일 화면](../specs/jobs.md#할-일-화면)
- 막는 티켓: [0063](0063-store-and-first-apply.md)

## 작업

- 보관한 자막의 회차에 영상이 없으면 영상 대기(Awaiting Video)로 둬요. Transmission이 아직 받고 있는 영상은 준비되지 않은 것으로 봐요.
- 영상이 들어오면(감시 알림이나 스캔) 다시 받거나 다시 고르지 않고 적용해요.
  그때 같은 줄기의 자막이 생겨 있으면 적용하지 않고 기존 파일을 그대로 둬요. 교체 승인으로 잇는 것은 [0068](0068-replacement-approval.md)이에요.
- 대기 작업과 보관본은 브라우저 종료, Anissia 줄 삭제, worker 재시작 뒤에도 남아요. 사용자가 정리하기 전까지 지우지 않아요.
- 회차 줄은 `영상 −`·`자막 ✓`와 `영상 대기` 배지이고, 펼친 자리에 영상이 아직 없는 까닭과 받은 자막을 보여줘요. 현재 배치된 자막이라고 표시하지 않아요.
- 할 일 화면 `자막 작업`과 작업 상세에서 대기 사유를 인증 필요와 구분해요.

## 완료 기준

| 입력·상태 | 기대 결과 |
| --- | --- |
| 영상이 없는 회차의 후보를 받음 | 보관되고 회차 줄에 `영상 −`·`자막 ✓`·`영상 대기`가 있어요. 영상 폴더에는 아무것도 없어요. |
| 그 회차의 영상 파일을 넣음(개발 환경) | 감시 알림으로 몇 초 안에 적용되고 배지가 사라져요. 받기 시도 기록이 늘지 않아요. |
| 영상이 Transmission에서 받는 중 | 적용하지 않고 기다려요. 받기가 끝나면 적용해요. |
| 대기 중에 worker 재시작, Anissia 줄 삭제 | 대기 작업과 보관본이 남아 있어요. |
| 영상과 함께 다른 자막이 생김 | 적용하지 않고 그 자막을 그대로 둬요. |
