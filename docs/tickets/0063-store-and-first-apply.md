# 0063 받은 자막 파일 하나를 보관하고 영상 옆에 처음 적용해요

- 상태: 대기
- 출처: [보관본과 적용본](../specs/subtitles.md#보관본과-적용본), [파일의 회차](../specs/subtitles.md#파일의-회차), [체크포인트와 중단 복구](../specs/jobs.md#체크포인트와-중단-복구), [작업 상세](../specs/jobs.md#작업-상세), [작업 결과](../specs/jobs.md#작업-결과)
- 막는 티켓: 없음

## 작업

목표 4의 첫 조각이에요. 후보 작업이 받은 자막 파일 하나가 보관과 첫 적용까지 처음부터 끝까지 가요.
보관의 DB 구조와 파일 효과의 기록을 여기서 정하고, 뒤 티켓은 이 위에 경우를 더해요(사용자 결정, 2026-10-04). 분석부터 만들면 그 결과를 쓰는 쪽이 없어 보관 구조를 짐작으로 정하게 돼서예요.

- 대상은 후보 작업(사용자가 고른 후보, 구독 제작자 자동 수신)에서 받은 자막 파일(ASS·SRT·SMI)이 하나뿐인 회차예요.
  압축 파일, 자막이 여럿인 회차, 폰트가 함께 온 회차는 [0064](0064-multi-file-packages.md)·[0065](0065-archive-extraction.md)를 기다리고, 그 까닭을 작업 상세에 적어요.
- 회차는 후보의 회차 표시를 그 출처의 회차 대응으로 옮긴 시즌 회차예요.
  파일 이름의 번호가 후보의 회차 표시나 옮긴 시즌 회차와 같거나 이름에 번호가 없으면 그 회차의 파일이고, 어느 쪽과도 다르면 보류해 `회차 확인 필요`로 물어요.
- 보관은 `.trss/subtitles/<제작자>/<원래 이름>`이고, 같은 이름·다른 내용은 번호를 붙여요.
  제작자 폴더 이름의 안전한 표기와 번호 붙이기(확장자 앞의 위치, 대소문자만 다른 이름)를 정해, 명세의 [남은 구체화](../specs/subtitles.md#남은-구체화)에서 [보관본과 적용본](../specs/subtitles.md#보관본과-적용본)으로 옮겨 적어요.
  DB는 [보관 관계 필드](../specs/settings.md#보관-관계-필드)의 묶음·보관본·자산과 같은 관계를 담아요. 보관을 확인하면 수신 영역의 원 수신물을 지워요.
- 첫 적용은 영상이 준비돼 있고 같은 줄기의 자막이 없을 때 해요. 보관본을 `.trss/` 안의 임시 파일로 복사·검증하고, 덮어쓰지 않는 이름 바꾸기로 영상 옆에 공개해요.
  같은 회차에 자막이 이미 있거나 공개할 이름이 차 있으면 적용하지 않고 기존 파일을 그대로 둬요(교체 승인은 [0068](0068-replacement-approval.md)). 영상이 없으면 보관까지만 하고 까닭을 적어요(영상 대기는 [0067](0067-awaiting-video.md)).
- 파일 효과마다 의도 → 증거 → 완료를 기록하고, 재시작한 worker는 [중단 위치 표](../specs/jobs.md#체크포인트와-중단-복구)대로 디스크와 대조해요.
- 목표 3에서 받기까지만 하고 끝난 작업은 worker가 다시 집어 이어가요(사용자 결정, 2026-10-04). 다시 받지 않아요.
- 화면은 작업 단계의 `보관`·`적용`, 작업 상세 경로 구역의 영상·적용본·보관본, 회차 줄의 `자막 ✓`, 라이브러리의 자막 범위예요.

## 완료 기준

| 입력·상태 | 기대 결과 |
| --- | --- |
| 목표 3에서 받아 둔 단일 자막 작업(개발 환경, 영상 있음) | worker가 다시 받지 않고 이어가요. `.trss/`에 보관본, 영상 옆에 같은 줄기의 적용본이 생기고 작업은 `완료`예요. 원 수신물은 지워졌어요. |
| 적용본을 고치거나 지움(시험) | 보관본의 내용은 그대로이고 다시 적용할 수 있어요. |
| 후보 `14`, 출처 대응 −12, 파일 이름 `Show - 13.ass` | 적용하지 않고 보류하며 `회차 확인 필요`가 생겨요. |
| 같은 제작자 폴더에 이름이 같고 내용이 다른 자막 | 덮어쓰지 않고 번호를 붙여 둬요. |
| 보관 복사, 적용 복사, 공개, 완료 기록의 각 사이에서 worker를 죽였다 살림(시험) | 중복 파일과 거짓 완료가 없고, 확인할 수 없는 상태는 보류해요. |
| 공개하기 직전에 그 이름에 다른 파일이 생김(시험) | 덮어쓰지 않고 그 회차를 보류해요. |
| 같은 회차에 이미 자막이 있음 | 적용하지 않고 기존 파일을 그대로 둬요. |
| 작업 상세 | 단계에 `보관`·`적용`이 시각과 함께 있고, 경로 구역에 영상·적용본·보관본이 나뉘어 있어요. |
| 작품 상세와 라이브러리 | 적용한 회차의 줄이 `자막 ✓`이고 라이브러리의 자막 범위에 들어요. |
