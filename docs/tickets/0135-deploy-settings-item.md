# 0135 설정의 `배포 설정`에 배포 값을 읽기 전용으로 보여줘요

- 상태: 대기
- 출처: [설정 화면](../specs/settings.md#설정-화면), [앱이 소유하는 설정](../specs/settings.md#앱이-소유하는-설정), [0113](0113-remaining-area-tests.md)에서 만든 [검증 표](../specs/settings.md#검증-표)(2026-10-10)
- 막는 티켓: [0114](0114-refactor-final-check.md)(리팩터링 마지막 확인)

## 작업

설정 명세의 설정 목록은 `배포 설정` 항목이 Transmission 주소·서버 포트·DB 위치 같은 배포 값을 읽기 전용으로 보여주고, 그 값은 배포 설정에서만 바뀐다고 한 문장으로 알리며, 비밀 값은 가린다고 해요.
2026-10-10 `6e46ef1`의 설정 화면(`web/src/screens/settings/items.ts`)에는 이 항목이 있지만 "배포 설정은 아직 보여줄 수 없어요."라는 빈 상태만 있고, 배포 값을 보내는 API도 없어요.
0113이 검증 표를 만들며 찾았어요. 기능을 더해야 맞출 수 있는 차이라서 리팩터링을 마친 뒤에 해요(사용자 결정, 2026-10-09). 이 항목을 티켓으로 둔 것은 그 결정에 따라 리드가 정했어요.

- 웹은 자기 환경 변수(`crates/trss-web/src/env.rs`)만 알고, Transmission 주소와 큐 크기는 worker의 배포 값이에요. 웹이 worker의 값을 어떻게 알지(worker가 시작할 때 DB에 적는 것 등)를 이 티켓에서 정해요.
- 보여줄 값의 목록은 명세의 [앱이 소유하는 설정](../specs/settings.md#앱이-소유하는-설정)이 배포 설정으로 나눈 값(Transmission 접속 주소·기존 속도 제한·큐 크기, 서버 포트, DB·앱 데이터 폴더 위치)이에요.

## 완료 기준

- 설정의 `배포 설정`이 위 값을 읽기 전용으로 보여주고, 비밀 값(주소에 든 사용자 이름·비밀번호 등)은 가려요. 가리는 것을 trss-web 테스트가 확인해요.
- 값이 바뀌는 곳은 배포 설정뿐이라는 문장이 있어요.
- [설정 명세의 검증 표](../specs/settings.md#검증-표)에서 이 요구의 행을 고쳐요.
