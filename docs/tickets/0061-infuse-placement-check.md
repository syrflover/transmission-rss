# 0061 Infuse에서 적용본과 `.trss/`가 어떻게 보이는지 확인해요

- 상태: 완료 (2026-10-07, 실제 서버의 작품 폴더에서 사용자가 확인했어요. 아래 "결과")
- 출처: [실제 재생 환경](../specs/subtitles.md#실제-재생-환경), [작품 폴더 배치 ADR](../adr/0008-trss-folder-and-app-data-files.md)
- 막는 티켓: 없음

## 작업

확인할 일이에요. 사용자가 Infuse로 한 번 확인하고, 저는 준비와 기록을 맡아요(사용자 결정, 2026-10-04). 세 재생기의 폰트 렌더링, 다시 읽기, 여러 형식의 선택은 목표 5예요.

- 보관본을 숨김 폴더 `.trss/`에 두는 배치(ADR 0003·0008)가 재생기의 자막 검색에서 빠지는지는 IINA 소스로만 확인했어요.
  Infuse가 숨김 폴더를 뒤진다면 배치를 다시 정해야 하므로, 보관을 만들기 전에 확인할 수 있게 막는 티켓 없이 둬요.
- 실제 서버의 시험 작품 폴더(또는 사용자가 정한 작품)에 손으로 파일을 둬요. 영상 옆에 같은 줄기의 `.ass`, `.trss/subtitles/<제작자>/` 안에 내용이 다른 `.ass`를 1000:1000으로 둬요.
- 사용자가 Infuse에서 NFS 공유로 그 영상을 열어 봐요.
  새 자막이 Infuse에 보이기까지 걸린 시간은 기록하지 않아요. 재생기의 캐시에 달린 일이라 trss가 바꿀 수 없고, 명세도 재생기가 바로 갱신된다고 가정하지 않아요(사용자 결정, 2026-10-07).
- 기록할 것은 Infuse 버전, 기기, 공유 방식과 경로, 자막 검색 설정이에요.

## 완료 기준

| 관찰 | 기대 결과 |
| --- | --- |
| 영상 옆 같은 줄기의 자막 | Infuse가 그 자막을 트랙으로 보여주는지가 기록돼 있어요. |
| `.trss/` 안의 자막 | Infuse의 자막 목록에 나오는지가 기록돼 있어요. 나오면 배치를 다시 정할 사용자 결정을 받아요. |
| 기록 | 재생기·버전·기기·공유 경로·설정이 날짜와 함께 이 티켓에 있어요. |

## 결과

2026-10-07에 사용자가 실제 서버(j4105)의 작품 폴더를 Infuse로 열어 봤어요. 0.6.0이 자막을 보관하고 적용한 폴더라서, 시험 파일은 따로 두지 않았어요.
수집 폴더의 `FX Senshi Kurumi-chan`(호스트 `/data/storage1/media/Shows (current)/FX Senshi Kurumi-chan`)이고, 안의 파일은 모두 1000:1000이에요.

| 파일 | 크기(바이트) | 구분 |
| --- | --- | --- |
| `.trss/subtitles/코코렛/[SubsPlease] FX Senshi Kurumi-chan - 01 (1080p) [99D53D33].smi` | 35186 | 보관본 |
| `.trss/tmp/` | | 빈 임시 폴더 |
| `Season 01/FX Senshi Kurumi-chan S01E01.mkv` | 1450917429 | 영상 |
| `Season 01/FX Senshi Kurumi-chan S01E01.smi` | 35186 | 적용본 |

| 관찰 | 결과 |
| --- | --- |
| 영상 옆 같은 줄기의 자막 | Infuse가 적용본을 자막으로 보여줬어요. |
| `.trss/` 안의 자막 | 보관본은 Infuse의 자막 목록에 나오지 않았어요. 그래서 배치(ADR 0003·0008)는 그대로 둬요. |

읽은 것이에요.

- 이 폴더는 운영의 배치 그대로예요. trname은 영상을 `<작품>/Season NN/<작품> SxxEyy.ext`에 두고, 라이브러리 검색은 시즌 폴더 밖의 영상을 회차로 읽지 않아요(`crates/trss-library/src/discovery.rs`). 그래서 `.trss/`는 언제나 영상 폴더보다 한 단계 위인 작품 폴더에 있어요.
- 보관본은 제작자가 붙인 원래 이름이고, 영상은 trname이 `<작품> SxxEyy`로 바꾼 이름이에요. 그래서 두 이름도 달라요.

이 결과로 알 수 없는 것이에요.

- 보관본이 영상 폴더의 위 폴더에 있고 이름도 달라서, Infuse가 숨김 폴더를 건너뛰어 안 보인 것인지 이름이 달라 안 보인 것인지는 가르지 못해요. 운영의 배치에는 두 조건이 늘 함께 있으므로 배치를 정하는 데는 이것으로 충분해요. 보관본의 원래 이름이 영상의 `<작품> SxxEyy`와 같은 경우는 보지 않았어요.
- 자막 형식은 SMI 하나였어요. ASS, 여러 형식의 선택, 폰트는 [0084](../archive/tickets/5-deployed-verification/0084-three-players.md)에서 봐요.
- Infuse 버전, 기기, Infuse에 등록한 공유 경로, 자막 설정은 기록하지 않았어요. 완료 기준의 `기록` 행이 비지만, 사용자가 이 관찰로 확인을 끝내기로 했어요(사용자 결정, 2026-10-07). 공유 방식은 명세에 적힌 NFS(사용자 확인, 2026-10-04)이고, 이번에 따로 확인하지 않았어요.
