# 0046 직접 찾기로 지난 회차 자막을 서버 브라우저에서 받아요

- 상태: 대기
- 출처: [직접 찾기와 자막 올리기](../specs/subtitles.md#직접-찾기와-자막-올리기), [지난 회차 ADR](../adr/0012-past-subtitles-find-and-upload.md)
- 막는 티켓: [0040](0040-remote-auth-screen.md), [0037](0037-candidate-section.md)(구역의 자리)

## 작업

연결 전에 지나간 회차처럼 관찰한 후보가 없는 자막을, 사용자가 서버 브라우저에서 직접 찾아 받게 해요.

- 자막 후보 구역의 `직접 찾기`에서 그 시즌 Anissia 작품의 제작자를 고르면, 그 제작자의 게시물을 연 서버 브라우저 작업이 생기고 작업 상세의 원격 화면이 열려요.
- 사용자가 지난 게시물로 옮겨 다운로드를 누르면, 같은 서버 브라우저가 받은 파일이 그 작업의 묶음이 되고 제작자는 고른 제작자예요. CAPTCHA는 같은 화면에서 풀어요.
- 사용자가 받기를 끝냈다고 누르면 작업이 다음 단계로 가요. 아무 파일도 받지 않고 끝내면 묶음 없이 끝났다고 기록해요.

## 완료 기준

| 입력·상태 | 기대 결과 |
| --- | --- |
| 가짜 블로그에서 지난 게시물로 이동해 첨부를 누름 | 받은 파일이 그 작업의 수신 영역에 있고, 작업 상세에 제작자·출처 `직접 찾기`가 있어요. |
| 한 작업에서 파일 두 개를 받음 | 두 파일이 한 묶음으로 남아요. |
| 아무것도 받지 않고 끝냄 | 받음이 아니라 받은 파일 없음으로 끝나요. |
| 유휴 시간이 지남 | 브라우저 수명 정책대로 닫히고, 이미 받은 파일은 남아요. |
| 실제 서버에서 실제 제작자 블로그의 지난 회차 하나 | 수동 다운로드·업로드 없이 서버가 받은 결과가 있어요. |
