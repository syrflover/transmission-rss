# 0003 웹 서버와 화면 골격을 세워요

- 상태: 대기
- 출처: [메뉴와 탐색](../specs/web-app.md#메뉴와-탐색), [시각 방향과 테마](../specs/web-app.md#시각-방향과-테마), [접근 경계와 기기](../specs/web-app.md#접근-경계와-기기), [웹 기술 ADR](../adr/0004-rust-react-web-stack.md), [웹·worker 분리 ADR](../adr/0006-separate-web-worker-binaries.md)
- 막는 티켓: 없음

## 작업

`trss-web` 바이너리가 axum으로 API와 React·TypeScript·shadcn/ui 정적 빌드를 함께 제공하고, 다섯 메뉴와 화면 모드를 갖춘 앱 골격을 보여줘요.
각 메뉴의 화면은 이 티켓에서 빈 자리와 제목만 두고, 내용은 해당 기능 티켓이 채워요.
운영용 Node 서버 없이 Rust 서버가 정적 파일을 제공하며, 빌드 이미지 하나에 `trss-web`과 이후의 `trss-worker`가 함께 들어가요.

- 주 메뉴는 `이번 주 편성`·`라이브러리`·`할 일`·`수집`·`설정`이고 앱 이름은 `TRSS`예요.
  PC는 상단, 휴대폰은 하단 메뉴이고, 721–979px에서는 상단 메뉴를 아이콘만으로 보여주되 이름은 보조 기술에 남겨요.
- 화면 모드는 상단의 한 칸짜리 전환 버튼(시스템·라이트·다크)이 맡고, 선택은 같은 브라우저에서 새로고침·이동 뒤에도 유지돼요.
- 색·간격·글꼴은 [기준 시안](../specs/web-app.md#목표와-범위)의 토큰을 출발점으로 삼아요.
  시안의 정적 HTML이나 직접 DOM 조작 코드를 제품 코드로 옮기지 않아요.
- 할 일 배지 자리는 두되, 할 일이 생기는 결과 목표 3 전에는 표시하지 않아요.
- 앱 자체 로그인은 두지 않아요.

## 완료 기준

- 배포 이미지를 빌드해 컨테이너로 띄운 `trss-web`이 Node 없이 화면과 API 응답을 제공해요.
- 1440·1024·768·390·320px 폭의 라이트·다크에서 골격 화면에 가로 페이지 넘침이 없고, 휴대폰 하단 메뉴가 안전 영역을 지켜요.
  폭별 확인은 헤드리스 브라우저로 하고, 실제 휴대폰 확인은 [0009](0009-deploy-web-worker.md) 뒤에 남은 확인으로 기록해요.
- 현재 메뉴가 색만이 아니라 배경·굵기·표시선으로 구분되고, Tab으로 다른 메뉴에 초점만 옮겼을 때 경로와 현재 메뉴 표시가 바뀌지 않아요.
- 태블릿 폭에서 아이콘만 보이는 메뉴가 보조 기술에 메뉴 이름을 전달해요.
- 화면 모드를 다크로 고른 뒤 새로고침하면 다크가 남고, 시스템을 고르면 기기 설정 변경을 따라가요.
