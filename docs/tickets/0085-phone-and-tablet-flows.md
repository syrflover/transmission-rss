# 0085 휴대폰과 태블릿으로 주요 흐름을 끝내 봐요

- 상태: 완료 (2026-10-07, 사용자 확인. 원격 페이지의 키보드 입력과 입력 초점은 확인하지 않은 것으로 남겼어요. 아래 "결과")
- 출처: [접근 경계와 기기](../specs/web-app.md#접근-경계와-기기)
- 막는 티켓: [0081](0081-deploy-new-release.md)

## 작업

명세는 PC, 태블릿, 휴대폰에서 구독, 후보 선택, 자막 비교와 승인, 설정 편집, 원격 인증을 끝낼 수 있어야 한다고 해요.
지금까지 휴대폰으로 확인한 것은 라이브러리, 작품 상세, 원격 화면의 인증처럼 티켓마다의 일부예요. 원격 화면에서 휴대폰의 가상 키보드로 원격 페이지에 글자를 넣는 것은 확인하지 않았어요(목표 3의 남은 것).
실제 서버의 웹을 실제 기기로 열어, 이 흐름들을 터치와 가상 키보드로 끝내 봐요. 사용자가 기기에서 하고, 저는 순서와 기록을 맡아요.

- 태블릿이 없으면 태블릿 폭은 확인하지 않은 것으로 남겨요.

## 완료 기준

| 흐름 | 확인할 것 |
| --- | --- |
| 구독, 후보 선택, 설정 편집 | 터치와 가상 키보드로 끝까지 가요 |
| 자막 비교와 승인 | 작은 화면에서도 비교 정보와 승인 동작이 빠지지 않아요 |
| 원격 인증 | 원격 화면을 확대하거나 기기를 돌린 뒤에도 보이는 위치와 누른 위치가 맞아요. 가상 키보드로 원격 페이지의 입력란에 글자가 들어가요 |
| 입력 초점 | 원격 입력에 초점이 있을 때와 trss의 다른 폼을 편집할 때 글자가 맞는 곳에 들어가요 |

- 기기, 운영체제, 브라우저 버전과 흐름마다의 결과가 결과 절에 있어요.

## 결과

### 휴대폰, LAN (2026-10-07)

사용자가 iPhone의 iOS 27 Safari로 LAN에서 실제 서버(0.6.0)의 웹을 열었어요. 기기 모델과 Safari의 세부 버전은 받지 않았어요.

| 흐름 | 결과 |
| --- | --- |
| 후보 선택 | `All Works Maid` 12화의 에루샤 후보를 골라 받았고, 9–11화의 보관본을 회차 줄에서 적용했어요([0083](0083-deployed-end-to-end.md)). 적용 뒤 화면이 바로 바뀌지 않은 것은 [0119](0119-refresh-after-stored-apply.md)예요. |
| 자막 비교와 승인 | `All Works Maid` 1화의 교체 비교를 열어 승인했어요(13:52 UTC, [0083](0083-deployed-end-to-end.md)). 작은 화면에서도 비교 정보와 `현재 유지`·`새 자막으로 교체`가 빠짐없이 보였다고 사용자가 알렸어요. |
| 원격 인증 | erulabo의 확인(Cloudflare Turnstile)이 원격 화면에 떴고, 사용자가 휴대폰에서 터치로 풀었어요. 화면을 확대하거나 돌린 뒤에도 누른 자리가 맞았다고 알렸어요. |

### 사용자 확인 (2026-10-07)

사용자가 0085의 확인을 마쳤다고 알렸어요. 태블릿은 iPad 13인치가 있다고 했어요. 어느 흐름을 어느 기기로 봤는지, 기기 모델과 운영체제·브라우저 버전은 받지 않았어요.

### 확인하지 않은 것

- 원격 페이지의 입력란에 가상 키보드로 글자를 넣는 것과 입력 초점이에요. 실제 서버에서 원격 화면이 뜬 확인(erulabo의 Turnstile)에는 입력란이 없어서, 입력란이 있는 확인이 생길 때까지 남겨요(사용자 결정, 2026-10-07).
- 이 기록에는 휴대폰으로 구독한 관찰이 없어요. 0.6.1을 올린 뒤 [0123](0123-collect-moves-archived-work-folder.md)의 서버 확인에서 지난 시즌이 `Shows`에 있는 속편을 휴대폰으로 구독해요.
