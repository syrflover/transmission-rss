# 0037 작품 상세의 자막 후보 구역에서 골라 받아요

- 상태: 대기
- 출처: [자막 후보 구역](../specs/library.md#자막-후보-구역), [자막 후보 조회](../specs/subtitles.md#자막-후보-조회), [할 일과 회차 목록](../specs/library.md#할-일과-회차-목록)
- 막는 티켓: [0035](0035-candidate-observation.md), [0036](0036-subtitle-jobs-foundation.md)

## 작업

작품 상세에서 자막을 한 번에 또는 골라 받게 해 달라는 요청(2026-10-02)을 명세의 자막 후보 선택과 합쳤어요. 선택한 시즌의 `할 일`과 회차 목록 사이에 `자막 후보` 구역을 둬요.

- 후보는 제작자·출처별로 접힌 줄이고, 펼치면 회차별 후보와 Anissia 갱신일이 보여요. 누락 회차 후보와 수정 후보(같은 회차에 같은 제작자의 자막이 이미 있음)를 구분해요.
- 제작자 단위의 `모두 받기`와 회차를 골라 받는 선택이 있고, 받기는 웹 명령으로 자막 작업을 만들어요. 선택은 행 위치가 아니라 후보 ID로 유지하고, 새로 나타난 후보를 자동으로 고르지 않아요.
- 회차 줄에는 구독 제작자가 올리지 않은 회차의 다른 제작자 후보를 조용히 적고, 펼친 자리의 `받기`가 같은 후보를 가리켜요.
- `새로고침`은 그 작품의 Anissia 자막 정보를 바로 읽어요(0035). `updDt`를 자막 공개일이나 방영일로 표시하지 않아요.
- 구독 제작자의 수정 후보는 자동으로 받으므로(0045) 구역에서는 받는 중이나 받음으로 보여요.
- Anissia 연결이 없는 시즌에는 후보 대신 `Anissia 연결`(0034)을 둬요.
- 출처별 수신이 아직 없는 후보로 만든 작업은 그 까닭(`자막 대기`)으로 기다려요.

## 완료 기준

| 입력·상태 | 기대 결과 |
| --- | --- |
| 두 제작자의 후보가 있는 시즌 | 접힌 줄 둘에 제작자·회차 범위·누락·수정 개수가 있고, 펼치면 회차별 후보가 보여요. |
| 한 제작자의 1–4화 가운데 2·3화만 골라 받기 | 2·3화만 담은 작업 하나가 생기고 작업 상세로 이어져요. 고르지 않은 후보는 받지 않아요. |
| `모두 받기` | 그 제작자의 누락 회차 후보 전체를 담은 작업이 생겨요. 수정 후보는 빠져요. |
| 같은 받기를 두 번 누르거나 응답이 끊겨 다시 보냄 | 같은 명령 ID로 작업이 하나만 생겨요. |
| 고르는 중에 새 조회로 후보가 늘어남 | 고른 것이 유지되고 새 후보는 고르지 않은 상태로 나타나요. |
| 구독 제작자가 올리지 않은 6화에 다른 제작자 후보만 있음 | 6화 줄에 색 없이 후보가 있다고 적히고, 펼친 자리의 `받기`로 받을 수 있으며, 할 일은 생기지 않아요. |
| Anissia 연결이 없는 시즌 | 후보 대신 `Anissia 연결`이 있어요. |
| 휴대폰 너비 | 구역과 펼친 후보에 가로 스크롤이 없어요. |
