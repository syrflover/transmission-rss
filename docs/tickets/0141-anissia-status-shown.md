# 0141 Anissia 방영 상태를 편성표 고르기, 구독 카드, 이번 주 편성에 보여줘요

- 상태: 완료 (2026-10-13, 개발 환경에서 확인. 서버 확인은 [0143](0143-deploy-feedback-fixes.md)에서 해요. 아래 "결과")
- 출처: [방영작 구독](../specs/collection.md#방영작-구독), [수집 화면](../specs/collection.md#수집-화면), [이번 주 편성](../specs/web-app.md#이번-주-편성), [문구와 표기](../specs/web-app.md#문구와-표기)의 Anissia 상태(2026-10-11에 더한 요구), 0.7.0을 써 본 사용자 피드백(2026-10-11)
- 막는 티켓: 없음

## 작업

Anissia는 작품마다 상태(`ON`·`OFF`·`END`)와 방영 시작일·종영일을 줘요. trss는 이 값을 `anissia_anime`에 저장해요. 0.7.0이 이 값을 보여주는 곳은 세 군데예요. 이번 주 편성 카드의 `결방`, 작품 상세의 Anissia 연결 구역과 연결 창, 보관 제안의 까닭(종영일)이에요. 작품 상세는 `OFF`를 `휴방`이라 불러요(`web/src/screens/library/detail/model.ts`의 `anissiaStatusText`).

사용자가 정한 것은 다음과 같아요(2026-10-11).

- 편성표에서 작품을 고르는 목록은 작품마다 `결방`·`종영`과 방영 시작일·종영일을 보여줘요.
- 수집 화면 구독 탭의 구독 카드는 `방영 중`·`결방`·`종영`과 종영일을 보여줘요.
- 이번 주 편성은 종영일이 든 주의 카드에 종영을 알려요. 0.7.0은 종영일이 지나면 표시 없이 카드를 빼요.
- `OFF`는 모든 화면에서 `결방`이라고 불러요. 작품 상세의 `휴방`도 바꿔요.

명세에 리드가 적은 것도 있어요. 사용자가 다르게 정하면 명세와 함께 고쳐요.

- 이번 주 편성 카드의 문구는 조용한 `이번 주 종영`이에요.
- AniList 항목의 `HIATUS`(`휴방`)는 다른 값이라 바꾸지 않아요(`airingBadge`).

다음은 이 티켓에서 정해요.

- **편성표 목록의 `종영`.** 편성표(`/anime/schedule/<week>`)는 `ON`·`OFF`만 줘요. 고르는 목록에서 `종영`을 무엇으로 판단할지(종영일이 지났는지 등) 정해요. 편성표에서 고르는 작품은 대개 방영 중이라, `종영`은 종영일이 지난 작품이 아직 편성표에 남은 경우에만 생길 수 있어요.
- **값이 바뀌는 때.** 구독 카드의 상태는 저장한 Anissia 값을 읽어요. 그 값이 언제 다시 읽히는지(편성표 갱신 주기) 확인하고, 카드가 낡은 상태를 보일 수 있는 때를 적어요.

## 완료 기준

- 편성표에서 고르는 목록, 구독 카드, 이번 주 편성 카드가 위 상태와 날짜를 보여줘요. 작품 상세의 `OFF`도 `결방`이에요.
- 상태를 정하는 규칙을 규칙을 가진 크레이트의 테스트가 확인해요. 다음 경우를 겨눠요.
  - 종영일이 이번 주에 든 작품의 카드는 `이번 주 종영`이에요.
  - 종영일이 지난 주에 있었던 작품은 카드가 없어요.
  - `OFF`인 작품은 `결방`이에요.
- [수집 명세](../specs/collection.md#검증-표)와 [웹 앱 공통 명세](../specs/web-app.md#검증-표)의 검증 표에서 이 요구의 행을 고쳐요.

## 결과

### 정한 것

- **편성표 목록의 `종영`.** 편성표가 싣는 작품은 종영일이 지났을 때만 `종영`이에요. 편성표는 `ON`·`OFF`만 주고, 실린 작품은 목록에서 빠졌다고 볼 수 없기 때문이에요. 2026-10-13의 실제 편성표에서는 기타의 극장판 두 편이 그랬어요.
- **값이 바뀌는 때.** 구독 카드와 이번 주 편성은 저장한 Anissia 값을 읽어요. worker는 수집 중이거나 멈춘 규칙이 구독한 작품의 값을 하루에 한 번 다시 읽어요(`trss-collect` `anissia` 모듈의 `REFRESH_AFTER_MS`). 그래서 Anissia가 `결방`을 정한 뒤 카드가 바뀌기까지 하루까지 걸릴 수 있어요. 보관한 구독의 값은 다시 읽지 않지만, 보관한 구독은 카드가 없어요. 편성표 고르기는 Anissia 편성표를 바로 읽고, 몇 분 동안은 읽어 둔 답을 써요.
- 상태를 정하는 규칙은 `trss-collect` `schedule::state::run_state`예요. 종영이 가장 앞서고, 다음이 시작 전, 다음이 `결방`이에요. 종영은 Anissia의 `END`와, 이번 주 편성이 카드를 빼는 규칙(`trss-anissia` `slot::run_over`)을 함께 써요. 가져오기가 Anissia에 묻지 못해 둔 임시 값(`fetched_at` 0)에는 상태가 없어요.
- `이번 주 종영`은 `trss-anissia` `slot::ends_in_week`가 정해요. 달까지만 아는 종영일은 주를 정할 수 없어 표시하지 않아요.

리드가 정한 것도 있어요. 사용자가 다르게 정하면 명세와 함께 고쳐요.

- 시작일이 오지 않은 작품의 구독 카드는 상태 대신 시작일을 보여줘요. Anissia는 시작 전 작품에도 `ON`을 줘서, `방영 중`이라고 하면 틀리기 때문이에요.
- 종영일은 그날이 오기 전에는 `12월 24일 종영 예정`, 지난 뒤에는 `12월 24일 종영`으로 적어요.
- 편성표 고르기 목록은 `결방`·`종영`만 표시하고 `방영 중`은 표시하지 않아요. 날짜 줄은 `22:30 · 10월 7일 시작 · 12월 23일 종영 예정`처럼 시각, 시작일, 종영일을 이어 적어요. 극장판처럼 시작일과 종영일이 같은 날이면 같은 날짜가 두 번 나와요.

### 개발 환경 확인 (2026-10-13)

f75ec6d 위에 0142(7773c81)와 이 변경을 얹은 작업 트리의 `trss-web`을, 로컬 개발 환경 DB의 복사본으로 띄워 내장 브라우저로 봤어요. 복사본의 구독은 `FX 전사 쿠루미`(목요일 21:30) 하나라서, 그 작품의 종영일과 상태를 바꿔 가며 봤어요.

| 넣은 값 | 이번 주 편성 | 구독 카드 |
| --- | --- | --- |
| 종영일 2026-10-15(이번 주 목요일), `ON` | 목요일 카드에 `21:30 3화 이번 주 종영` | `목요일 21:30`, `방영 중`, `10월 15일 종영 예정` |
| 종영일 2026-10-15, `OFF` | `결방` 카드에 `ends_this_week: true` (API 값) | `run: "off"` (API 값) |
| 종영일 2026-10-08(지난주), `ON` | 카드 없음 | `run: "end"` (API 값) |

편성표 고르기는 실제 Anissia 편성표를 읽었어요. 일요일의 `원피스`가 `결방`, 토요일의 `블리치 천년혈전 편`이 API 값으로 `off`, 기타의 극장판 두 편이 `종영`이었고 줄마다 시작일과 종영일이 있었어요. 1440·768·390·320px의 라이트·다크에서 이번 주 편성, 구독 탭, 편성표 고르기에 가로 넘침이 없었어요(24개 조합).

`cargo test -j 4 -p trss-anissia -p trss-collect -p trss-web`이 모두 통과했어요. 새 테스트는 다음과 같아요.

- `trss-anissia` `slot.rs` `the_week_of_the_end_date_is_the_last_one_and_says_so`: 종영일이 이번 주에 든 작품은 이번 주 카드가 있고 `이번 주 종영`이에요. 지난주에 끝난 작품은 카드가 없어요. 다음 주에 끝나거나 달만 아는 종영일은 표시하지 않아요.
- `trss-collect` `schedule/state.rs` `the_run_state_is_the_end_then_a_start_to_come_then_off`: `OFF`는 `결방`이고, 종영일이 지나면 `OFF`여도 `종영`이에요. `END`, 목록에서 빠짐, 시작 전, 임시 값도 겨눠요.
- `trss-web` `schedule_api/tests.rs` `the_card_of_the_week_the_anime_ends_says_so`와 `subscriptions_api/tests.rs`의 `run` 확인 세 곳: 응답 모양만 봐요.

### 확인하지 않은 것

- 구독 카드 화면의 `결방`·`종영`과 이번 주 편성 카드의 `결방`과 함께 나온 `이번 주 종영`은 API 값으로만 봤어요.
- 작품 상세의 Anissia 연결 구역이 `OFF`를 `결방`이라 부르는 것은 화면에서 보지 않았어요. 복사본에 Anissia를 이은 `OFF` 작품이 없었어요.
- 화면 테스트는 없어요. 서버 확인은 [0143](0143-deploy-feedback-fixes.md)에서 해요.
