# 0083 실제 서버에서 구독부터 자막 적용까지 이어 봐요

- 상태: 진행 중(구독 제작자의 자막을 화면에서 봤어요. 나머지 흐름은 작품 연결과 다음 회차를 기다려요)
- 출처: [검증 근거와 완료 판정](../specs/web-app.md#검증-근거와-완료-판정), [보관본과 적용본](../specs/subtitles.md#보관본과-적용본), [방영작 구독](../specs/collection.md#방영작-구독)
- 막는 티켓: [0081](0081-deploy-new-release.md)

## 작업

목표 3·4의 관찰은 개발 환경에서 실제 외부 사이트와 서버 DB 복사본으로 했어요(사용자 결정, 2026-10-04). 명세는 실제 배포 이미지에서도 자막 기능과 화면이 동작하는지 확인하라고 해요.
새 릴리스가 올라간 실제 서버에서 사용자가 쓰는 흐름을 한 번씩 끝까지 이어 봐요. 결과는 웹 화면과 미디어 디스크의 파일로 함께 확인해요.

- 실제 방영작과 실제 제작자를 써요. 새 회차가 나오기를 기다려야 하는 관찰은, 이미 있는 회차로 같은 경로를 탈 수 있으면 그것으로 대신하고 그렇게 했다고 적어요.
- 원격 화면의 인증은 사용자가 휴대폰에서 해요.
- 0081의 배포 첫 주기(2026-10-07)에 구독 제작자(코코렛)의 자막 작업이 `FX Senshi Kurumi-chan` 1화에 돌아, 영상 옆의 적용본과 `.trss/`의 보관본을 1000:1000으로 만들었어요([0081 결과](0081-deploy-new-release.md#자막-작업과-미디어-디스크)). 이것을 "구독 제작자의 자막" 흐름의 관찰로 쓰려면 두 파일의 바이트 비교와 작품 상세의 화면 확인이 남았어요.

## 완료 기준

| 흐름 | 확인할 것 |
| --- | --- |
| 구독에서 첫 수집까지 | 편성에서 구독한 작품의 회차가 Transmission에 들어가고, 받은 영상이 라이브러리의 그 작품·시즌에 나타나요 |
| 구독 제작자의 자막 | 구독 제작자의 자막이 선택 없이 받아져 `.trss/`의 보관본과 영상 옆의 적용본이 돼요 |
| 고른 후보의 자막 | 작품 상세에서 고른 후보가 같은 곳까지 가요 |
| erulabo | 휴대폰의 원격 화면에서 사람이 CAPTCHA만 풀고, 파일이 적용본까지 가요 |
| 교체 승인 | 자막이 있는 회차에 새 자막이 오면 교체 승인에서 멈추고, 승인한 회차만 바뀌어요 |
| 영상 대기 | 영상이 없는 회차의 자막은 영상이 들어온 뒤 다시 받지 않고 적용돼요. 기다릴 회차가 없으면 확인하지 않은 것으로 남겨요 |

- 보관본과 적용본은 1000:1000이고, 영상 옆 적용본의 바이트가 보관본과 같아요.
- 흐름마다 날짜, 작품, 관찰한 화면과 파일이 결과 절에 있어요. 관찰하지 못한 흐름은 까닭과 함께 남은 일에 있어요.

## 결과

### 서버의 상태 (2026-10-07)

LAN의 개발 PC에서 실제 서버의 웹 API를 읽었어요(13:30 UTC 무렵, 읽기만 했어요).

- 구독은 `FX Senshi Kurumi-chan` 하나예요. Anissia 3424(목요일 21:30), subsplease.org, 구독 제작자 코코렛을 따라 받기예요. 구독은 2026-10-02 01:00 UTC에 만들었고, 1화 영상은 01:07 UTC에 라이브러리에 들어왔어요. 둘 다 0.5.0 때예요.
- 라이브러리의 시즌 140개 가운데 Anissia에 연결된 시즌은 이 작품의 시즌 1 하나예요. 그 시즌의 Anissia 제작자는 코코렛 한 명이에요. 그래서 고른 후보, erulabo, 교체 승인 흐름에는 다른 시즌의 Anissia 연결이 먼저 필요해요.

### 구독 제작자의 자막 (2026-10-07)

0081의 배포 첫 주기에 자동 작업(`bb5950bb`, 코코렛, felia.tistory.com, 1화)이 12:00:31 UTC에 생겨 3초 뒤 끝났어요. 사용자가 서버에서 본 작품 폴더예요. 모두 1000:1000이에요.

| 파일 | 크기(바이트) |
| --- | --- |
| `.trss/subtitles/코코렛/[SubsPlease] FX Senshi Kurumi-chan - 01 (1080p) [99D53D33].smi` | 35186 |
| `Season 01/FX Senshi Kurumi-chan S01E01.smi` | 35186 |

- 작품 상세(개발 PC의 브라우저, 13:35 UTC 무렵)에서 1화 줄은 영상 `보유`, 자막 `보유`였어요. `자막` 카드는 `제작자 1명 · 자막 1개`였고, 코코렛의 보관본이 그 적용본에 적용된 것으로 나왔어요.
- 결함: 머리의 자막 제작자가 `코코렛, 제작자 알 수 없음`이에요. 적용 단계가 영상 옆 파일에 제작자(`media_files.creator_source_id`)를 붙이지 않아서, 머리(`headNames`)가 trss가 적용한 이 파일을 제작자 모르는 파일로 세요. [머리와 시즌](../specs/library.md#머리와-시즌)은 직접 넣은 파일처럼 제작자를 모를 때만 `제작자 알 수 없음`을 보여 달라고 해요. 적용본의 제작자를 보관본에서 읽도록 [0118](0118-applied-copy-creator.md)에서 고쳐요(사용자 결정, 2026-10-07).
- 두 파일의 바이트가 같은지는 크기만 봤어요. SHA-256 비교가 남았어요.

### 남은 일

- 구독에서 첫 수집까지: 2화(2026-10-08 목요일 방영)가 0.6.0에서 Transmission과 라이브러리에 들어오는지 봐요. 같은 회차로 구독 제작자의 자막도 한 번 더 봐요.
- 고른 후보, erulabo, 교체 승인: `All Works Maid` 시즌 1을 Anissia 3492에 연결해서 해요(사용자 결정, 2026-10-07). 2026-10-07에 Anissia에서 이 작품의 제작자는 에루샤 하나이고, 마지막 줄은 12화(erulabo.com/837, 09-10)였어요. 라이브러리에서 1–8화에는 자막이 있고 12화에는 없어요.
  - 12화 후보를 고르면 고른 후보, erulabo, 원격 인증을 봐요. 자막이 없는 회차라 확인 없이 적용돼야 해요.
  - 직접 찾기로 에루샤의 1화 게시물을 받으면 교체 승인을 봐요. 1화에는 관리하지 않던 자막이 있어서, 승인하면 그 자막은 `제작자 알 수 없음` 보관본으로 들어가야 해요.
  - 휴대폰으로 하면 [0085](0085-phone-and-tablet-flows.md)의 후보 선택, 비교와 승인, 원격 인증과 [0082](0082-deployed-access-boundary.md)의 원격 화면 입력도 함께 관찰돼요.
- 영상 대기: 기다릴 회차가 생기지 않으면 확인하지 않은 것으로 남겨요.
