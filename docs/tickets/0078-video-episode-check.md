# 0078 회차를 정하지 못한 영상을 `회차 확인 필요`로 올려요

- 상태: 대기
- 출처: [할 일](../specs/jobs.md#할-일)의 `회차 확인 필요`(받은 영상의 회차를 확정하지 못함), [할 일과 회차 목록](../specs/library.md#할-일과-회차-목록)의 회차 확인 카드. [0075](0075-todo-badges-and-cards.md)에서 이 카드를 만들 할 일이 없어 새 티켓으로 나눴어요(사용자 결정, 2026-10-06).
- 막는 티켓: [0075](0075-todo-badges-and-cards.md)(격자 배지와 작품 상세의 `할 일`)

## 작업

- 받은 영상의 회차를 정하지 못한 경우를 `회차 확인 필요` 할 일로 만들어요. 2026-10-06에는 이 할 일이 없고, 이름에서 회차를 읽지 못한 영상은 작품 상세 `파일` 카드의 `회차를 확인하지 못한 파일`에만 나와요.
- 작품 상세 `할 일`의 회차 확인 카드는 확인할 RSS 항목 이름 조각을 제목으로 둬요. 격자의 배지와 메뉴 개수는 다른 처리 필요와 같은 규칙을 따라요.
- 시작하기 전에 사용자와 정할 것이 있어요.
  - 무엇을 할 일로 셀지: 이름에서 회차를 읽지 못한 영상(`unrecognized_files`의 `no_episode`)만인지, 시즌 폴더 밖·하위 폴더 같은 다른 까닭도 넣을지, 받는 중인 파일은 뺄지예요.
  - 어떻게 사라지는지: 앱 안에서 회차를 정하는 기능이 없어서, 지금은 파일 이름을 고치거나 옮겨야 사라져요. 앱에서 회차를 정하는 기능을 더할지 정해요.
  - 제목의 RSS 항목 이름: 수집 기록에서 그 파일을 받은 항목을 찾을 수 있는지, 없으면 파일 이름 조각을 쓸지예요.

## 완료 기준

| 입력·상태 | 기대 결과 |
| --- | --- |
| 회차를 정하지 못한 영상이 있는 작품 | 격자 표지에 `회차 확인 필요` 배지가 있고, 작품 상세 `할 일`에 확인할 이름 조각을 제목으로 한 카드가 있어요. 임의의 회차에 붙이거나 누락으로 단정하지 않아요. |
| 그 영상의 회차가 정해짐 | 배지와 카드가 사라져요. |
