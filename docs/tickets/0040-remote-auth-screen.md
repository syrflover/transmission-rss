# 0040 작업 상세에서 원격 화면으로 인증해요

- 상태: 대기
- 출처: [작업 화면 안의 인증과 브라우저 수명](../specs/jobs.md#작업-화면-안의-인증과-브라우저-수명), [작업 상세](../specs/jobs.md#작업-상세), [접근 경계와 기기](../specs/web-app.md#접근-경계와-기기)
- 막는 티켓: [0039](0039-browser-container-lifecycle.md)

## 작업

작업 상세의 인증 상태에 서버 브라우저의 원격 화면·마우스·키보드 입력을 붙여요. 방식은 0032에서 정한 것을 따라요.

- 화면·입력 연결은 웹을 거치며, 원격 화면 페이지와 같은 접근 보호를 받아요. 외부 페이지에서 보낸 연결이나 다른 작업·끝난 실행으로의 연결은 거부해요.
- 휴대폰에서 열면 0032의 기준으로 원격 페이지를 휴대폰 배치로 맞추고, 기기를 바꿔 열면 다시 맞추며, 맞추는 동안의 입력은 섞이지 않게 해요. 휴대폰에서는 단계를 한 줄로 접어 사람 확인 상자가 첫 화면에 보이게 해요.
- 원격 화면 옆에 원격 페이지 `새로고침`을 둬요.
- 연결이 끊기면 같은 작업의 유효한 실행에 다시 붙고, 유휴 종료된 실행을 재연결 시도만으로 다시 띄우지 않아요. 사용자가 작업을 다시 열면 페이지와 인증 화면을 다시 준비해요.
- 할 일의 `인증 필요` 카드와 작품 상세의 인증 카드가 이 화면으로 이어져요.

## 완료 기준

| 입력·상태 | 기대 결과 |
| --- | --- |
| 가짜 CAPTCHA 페이지의 인증 필요 작업을 PC에서 엶 | 원격 화면에서 클릭·입력이 서버 브라우저에 전달되고, 통과하면 작업이 `받기`로 넘어가요. |
| 실제 휴대폰에서 같은 작업을 엶 | 한 줄로 접힌 단계 아래 원격 화면의 사람 확인 상자가 첫 화면 안에 보여요. |
| 유휴 종료된 인증 필요 작업을 엶 | 단계는 `인증`에 머물고 브라우저와 인증 화면이 다시 준비돼요. 받은 파일과 기록은 그대로예요. |
| 화면을 열어 둔 채 입력 없이 유휴 시간이 지남 | 브라우저가 닫히고, 화면은 다시 열면 준비된다고 알려요. 연결 재시도가 브라우저를 계속 띄우지 않아요. |
| 다른 출처(Origin)의 페이지에서 원격 입력 연결 시도, 끝난 실행의 연결로 입력 | 모두 거부돼요. |
| 웹만 재시작 | 같은 작업의 유효한 원격 화면에 다시 연결되고 브라우저가 새로 뜨지 않아요. |
