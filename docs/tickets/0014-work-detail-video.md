# 0014 작품 상세에서 시즌과 회차의 영상·자막 보유를 봐요

- 상태: 진행 중
- 출처: [작품 상세 화면](../specs/library.md#작품-상세-화면)
- 막는 티켓: [0012](0012-watch-folders-discovery.md), [0013](0013-library-screen.md)

## 작업

라이브러리에서 작품을 열면 한 번에 스크롤하는 작품 상세가 나오고, 시즌을 골라 회차마다 영상·자막 파일이 있는지 봐요.
영상 쪽과 디스크에서 찾은 파일까지가 범위이며, 할 일 카드·자막 후보·교체 승인·작품 정보는 결과 목표 3·4와 시즌 정보 연결 뒤에 붙어요.

- 머리는 표지 자리([0015](0015-work-artwork.md) 전까지 빈 표지), 작품명(폴더 이름)이에요. 원제는 모르면 두지 않아요.
  자막 제작자는 디스크에서 찾은 자막만 있으면 `제작자 알 수 없음`이에요. `제작자 변경`은 구독 제작자가 생기는 구독·자막 목표에서 붙여요.
- 시즌 타일과 휴대폰의 `시즌 변경` 시트는 명세의 선택·초점·크기 조건 그대로이고, 시즌이 하나면 숨겨요.
- 시즌 정보 칸(방영·분량·제작사·장르)과 AniList 링크는 시즌마다 AniList 항목을 연결하는 티켓(0015 다음)이 붙을 때까지 두지 않아요. 모르는 값을 다른 시즌이나 파일 상태로 채우지 않는다는 조건을 지키는 선택이에요.
- 회차 목록은 최신 화부터이고 `1화부터`로 바꿀 수 있어요. 줄은 회차·`영상 ✓`·`자막 −` 보유 표시이고, 누르면 영상 파일·자막 파일·추가 시각(미상 포함)을 이름표 달린 칸으로 펼쳐요.
  방영일은 시즌 정보와 함께 붙어요.
- 오른쪽 카드 열(휴대폰은 목록 아래 접힌 구역)에는 지금 `수집`과 `파일`만 둬요.
  `수집`은 이 작품 폴더에 받는 규칙과 규칙 상세 링크이고, `파일`은 작품 폴더 경로, 회차별 파일 대응, 회차를 확인하지 못한 파일이에요.
- 작품 폴더가 `폴더 없음`이면 머리 아래에 그 까닭을 한 줄로 두고, 마지막으로 본 기록을 보여줘요.
- 편성·할 일에서 특정 시즌·회차를 가리키는 주소로 들어오면 그 시즌을 고르고 그 회차로 스크롤해 초점을 옮겨요.

## 완료 기준

| 입력·상태 | 기대 결과 |
| --- | --- |
| 영상이 1–12화, 자막이 4·6화만 없는 시즌 | 4·6화 줄에 `영상 ✓`·`자막 −`이고 나머지는 둘 다 `✓`예요. `영상`·`자막` 라벨은 보유 여부와 관계없이 같은 크기이고, 보조기술에 보유·없음이 읽혀요. |
| 회차 줄을 누름 | 영상·자막 파일 이름과 추가 시각(첫 확인 때 있던 파일은 `미상`)이 펼쳐져요. |
| `1화부터`로 바꿈 | 1화가 맨 위예요. |
| 두 시즌이 있는 작품, 넓은 화면 | 두 타일이 보이고 선택한 타일에만 체크가 있으며, 선택 전후 타일 크기가 같아요. 시즌을 바꾸면 회차 목록이 바뀌어요. |
| 같은 작품, 휴대폰 너비 | 현재 시즌 타일과 `시즌 변경`이 보이고, 시트에서 고르면 닫혀요. Escape·배경·닫기 버튼으로 닫으면 초점이 여는 버튼으로 돌아가요. 가로 스크롤이 없어요. |
| 시즌이 하나인 작품 | 타일과 시트 버튼이 없어요. |
| `?season=2&episode=5` 같은 주소로 진입 | 시즌 2가 골라지고 5화 줄로 스크롤해 초점이 가요. |
| 규칙 두 개가 이 작품 폴더에 받는 작품 | `수집` 카드에 두 규칙이 있고 누르면 수집 화면의 그 규칙 상세로 가요. |
| 회차를 확인하지 못한 파일이 있는 작품 | `파일` 카드에 그 파일들이 까닭과 함께 보여요. 회차 줄에 임의로 붙지 않아요. |
| 작품 상세에서 뒤로 가기 | 라이브러리의 검색·필터·스크롤이 그대로예요([0013](0013-library-screen.md)). 열려 있던 시트가 남지 않아요. |

## 결과

### 구현한 것

- 읽기 API `GET /api/library/works/{id}`(`crates/trss-web/src/library_work_api.rs`, 읽기는 `crates/trss-library/src/store/library/detail.rs`): 작품명(폴더 이름), `missing`, 감시 폴더와 작품 폴더 경로(`folder_path`), 작품 추가 시각, 시즌(번호 오름차순, 회차 없는 시즌 폴더도 빈 목록으로), 회차(적힌 그대로의 `episode`, 숫자 `sort`, 영상·자막 파일의 상대 경로와 추가 시각, 모르면 `null`), 회차를 확인하지 못한 파일(이유 코드와 해요체 문장), 이 작품 폴더에 받는 규칙을 한 번에 답해요. 모르는 ID는 JSON `404`예요. 0012의 저장·발견 코드는 고치지 않고 `store/library/mod.rs`에 모듈 선언과 `work_detail` 하나만 더했어요.
  - 회차는 라이브러리 목록과 같이 숫자로 견줘요. `013`과 `13`은 한 회차이고 더 작은 적힌 글자(`013`)로 두 파일을 함께 가져요. `17.5`는 `17`과 `18` 사이에, 숫자가 아닌 회차(`SP`)는 맨 뒤에 놓여요. 회차 번호는 `u128`과 소수부 글자로 견주고 `f64`로 바꾸지 않아요(`sort`는 화면에 쓰지 않는 참고 값이에요).
  - 규칙은 `directory`의 첫 마디(`rule_archive::work_folder`)가 이 작품의 폴더 이름이고, 작품의 감시 폴더가 수집 폴더 또는 보관 폴더일 때만 이어요. 보관한 규칙(`state: archived`)도 목록에 있고 상태가 붙어요. `..`가 들어 있는 저장 폴더, 수집 폴더 자체, 이름이 접두사만 같은 폴더는 이어지지 않아요. 수집 폴더가 정해지지 않았으면 규칙이 없어요. `save_path`는 `rss::save_path`로 만들어요.
- 화면(`web/src/screens/library/WorkDetailScreen.tsx`, `detail/`): 머리(0013의 표지 자리, 작품명, 선택한 시즌에 자막이 있으면 `자막 제작자 제작자 알 수 없음`, 없으면 아무것도 두지 않아요), 시즌 타일, 회차 목록, `수집`·`파일` 카드. 시즌 정보 칸·AniList 링크·방영일·할 일·자막 후보와 교체 승인·`작품 정보`·`자막`·`최근 활동` 카드·표지 확대는 티켓 범위 밖이라 두지 않았어요.
  - 시즌 타일: 넓은 화면(721px부터)은 모든 시즌 타일이 보이고 선택한 타일에만 체크가 있어요. 타일의 테두리 두께·글자 굵기·체크 자리는 선택과 관계없이 같고(체크는 `invisible`), 선택은 테두리 색·옅은 배경·안쪽 선만 바꿔요. 휴대폰(720px 이하)은 현재 시즌 타일과 `시즌 변경`이고, 시트(`web/src/components/ui/sheet.tsx`, Radix Dialog)는 고르면 닫혀요. Escape·배경·닫기 버튼이 닫고 초점은 `시즌 변경`으로 돌아가요. 여는 순간 초점은 선택된 시즌 타일에 가요. 시즌이 많으면 시트 안에서 세로로 스크롤하고 가로 스크롤은 없어요. 시즌이 하나면 타일과 시트 버튼이 없어요. 처음 보이는 시즌은 가장 높은 번호예요.
  - 회차 목록: 최신 화부터가 기본이고 `최신 화부터`·`1화부터` 선택(`localStorage` `trss-work-v1`, 접근을 `try/catch`로 감쌈)으로 바꿔요. 줄은 `12화`·`영상 ✓`·`자막 −`이고 `영상`·`자막` 라벨은 보유와 관계없이 같은 크기·굵기예요(13px/600). 체크·빼기 표시 옆에 보이지 않는 글자 `보유`/`없음`이 있어요. 줄을 누르면 `영상 파일`·`자막 파일`·`추가 시각`(영상·자막 줄마다, 모르면 `미상`)을 이름표 달린 칸으로 펼쳐요.
  - 오른쪽 카드 열(1100px 이상)은 시즌 타일 윗면에 맞춰 시작하고 화면과 함께 스크롤해요. `수집`은 규칙마다 일치 문구·채널 이름(없으면 호스트)·저장 폴더를 보여주고 누르면 `/collect/rules?rule=<ID>`로 가요. `파일`은 작품 폴더 경로, `회차 N개의 파일 보기`(접힘, 시즌별 회차→영상·자막 파일), 회차를 확인하지 못한 파일(경로와 까닭)이에요. 1100px 미만(휴대폰 포함)은 두 카드가 목록 아래에서 접힌 채 시작하고 단추에 한 줄 요약(`규칙 2개`, `확인하지 못한 파일 6개`)이 있어요.
  - 폴더 없음(`missing`): 머리 아래 한 줄(`폴더 없음 작품 폴더를 찾지 못했어요. 지워졌거나 옮겨졌거나 마운트가 풀렸을 수 있어요. 아래는 마지막으로 확인한 기록이에요.`), 회차 제목은 `마지막으로 본 기록`, 보조기술 글자는 `기록 있음`/`기록 없음`, 타일은 `영상 기록 1–12화`예요(0012가 읽는 쪽에 남긴 일: 폴더 없음 작품의 파일을 지금 있는 것으로 세지 않아요).
  - 주소 `?season=N&episode=E`: 그 시즌을 고르고(없는 시즌이면 무시), 해당 회차 줄로 스크롤해 초점을 옮겨요(앞 `0`을 뗀 회차로 견줘요). 같은 화면에서 주소가 바뀌어도 다시 적용해요. 줄 초점에는 배경이 옅게 바뀌어요.
  - 뒤로 가기: 0013의 `라이브러리로`/브라우저 뒤로 가기를 그대로 두었고, 작품마다 화면이 새로 만들어져(`key`) 시즌 선택·펼친 줄·시트가 다른 작품으로 넘어가지 않아요. 작품 답은 `useCached`(`library:work:<ID>`)로 두어 다시 열면 이전 답을 먼저 보여주고 뒤에서 새로 읽어요.
  - 존재하지 않는 작품: `이 작품을 찾지 못했어요. 폴더가 감시 폴더에서 빠졌을 수 있어요.`와 `라이브러리로`예요(API의 `404`를 `null`로 받아요).

- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`(373개 통과, 기존 무시 2개)와 웹 `npm run typecheck`, `npm run build`가 통과했어요.
- Rust 시험: `detail.rs`(숫자 순서·`013`=`13`·`17.5`·`SP`·`f64`로 표현할 수 없는 큰 회차·숫자가 아닌 글자, 시즌·회차·파일·확인하지 못한 파일, 빈 시즌 폴더, 폴더 없는 작품의 기록 보존), `library_work_api/tests.rs`(응답 모양, 모르는 ID의 JSON 404, 목록 경로와 겹치지 않음, 규칙 이음: 같은 폴더 이름만·접두사·`..`·수집 폴더 자체 제외, 보관 폴더의 작품과 보관 규칙, 다른 감시 폴더의 작품은 규칙 없음, 수집 폴더 미설정).
- 브라우저(로컬 `trss-web`, 스크래치 DB, 만든 감시 폴더 하나에 작품 10개, 1280×900과 390×844, 2026-10-01):
  - 영상 1–12·자막 4·6화 없음(`Single Season`): 4·6화 줄만 `영상 ✓`·`자막 −`이고 보조기술 글자는 `보유,없음`, 나머지는 `보유,보유`예요. 두 라벨 모두 13px/600이에요. 시즌이 하나라 타일과 `시즌 변경`이 없어요.
  - 줄을 누르면 파일 이름과 추가 시각이 펼쳐져요(시각을 넣은 1화는 `9월 30일 20:52`, 나머지는 `영상 · 미상`·`자막 · 미상`, 자막 없는 6화는 `자막 파일 없음`).
  - `1화부터`로 바꾸면 1화가 맨 위이고 선택이 새로고침 뒤에도 남아요.
  - `Two Seasons` 1280px: 두 타일(380.5×96.4px), 시즌을 바꾸기 전후 크기가 같고(둘 다 380.5×96.4), 체크는 선택한 타일에만 보이며(`visibility`), 시즌 1은 4개·시즌 2는 6개 줄이고 제목이 `시즌 N 회차`로 바뀌어요. 오른쪽 카드 윗면이 타일 윗면과 맞아요.
  - 같은 작품 390px: 현재 시즌 타일과 `시즌 변경`만 있고(`aria-pressed` 타일 없음), 시트를 클릭·키보드(Enter)로 여닫았어요. 시트에서 시즌 고르기(클릭, Tab+Enter), 현재 시즌 다시 고르기(Enter), Escape, 배경 누르기, 닫기 버튼 모두 시트가 닫히고 `document.activeElement`가 `시즌 변경`이에요. 시트가 열려 있는 동안 Tab은 시트 안(타일 1→타일 2→닫기→타일 1)에서만 돌아요. 시트가 닫히면 `body`의 `overflow`·`pointer-events`가 원래대로예요. 시즌 8개짜리(`Eight Seasons`)는 시트 안에서 세로로만 스크롤하고(콘텐츠 869px/뷰 647px, 가로 `hidden`) 열 때 선택된 시즌 8에 초점이 가요. 모든 390px 화면에서 `scrollWidth == innerWidth`이고 폭을 넘는 요소가 없어요.
  - `?season=2&episode=5`(1280px)는 시즌 2가 골라지고 `ep-s2-e5`에 초점이 가요. `?season=1&episode=3`(390px)은 기본 시즌(2) 대신 시즌 1이 골라지고 3화 줄에 초점이 가요. `?season=1&episode=7`(60화, 390px)은 7화 줄이 화면 가운데 근처로 스크롤돼요.
  - 규칙 두 개가 받는 작품(`Single Season`: `Single Season/Season 01`, `Single Season/Specials`): `수집` 카드에 두 규칙이 있고, 규칙 링크를 눌러 `/collect/rules?rule=…`의 규칙 상세가 열리는 것을 `Two Seasons`에서 확인했어요.
  - `Leftovers`: `파일` 카드에 확인하지 못한 파일 6개가 까닭과 함께 있고(시즌 폴더 밖, 받는 중, 이름의 시즌이 다름, 회차를 읽지 못함 2, 하위 폴더), 회차 줄은 1·2화뿐이에요.
  - `Gone Work`(폴더 없음): 머리 아래 한 줄, 제목 `마지막으로 본 기록`, 보조기술 글자 `기록 있음`.

### 검증하지 못한 것

- 브라우저 확인에서 창이 가려져 `:focus` 스타일이 적용되지 않고(`document.hasFocus()`가 `false`), 스크롤한 채의 스크린샷이 어긋나요. 딥링크로 이동한 줄의 초점 표시(옅은 배경)는 눈으로 보지 못했고 `document.activeElement`로만 확인했어요. 시트의 여닫는 움직임도 눈으로 보지 못했어요(닫힘 상태 표시·초점·본문 잠금은 확인했어요).
- 실제 휴대폰·터치, 스크린 리더로 읽은 결과(보이지 않는 글자와 `aria-pressed`·`aria-expanded`가 DOM에 있는 것까지만 봤어요), 1100px 근처와 태블릿 너비(721–1099px)의 화면은 보지 않았어요. 1280px과 390px만 걸어 봤어요.
- 회차가 수백 개인 작품(60개까지만 시험)과 파일이 매우 많은 작품의 그리기 시간은 재지 않았어요. 가상화는 넣지 않았어요.
- 추가 시각은 시험 자료의 DB 값을 직접 바꿔 섞었어요(worker가 만든 시각은 0012 시험이 확인해요). 규칙 이음은 수집 폴더와 같은 감시 폴더의 작품으로만 브라우저에서 봤고, 보관 폴더의 작품은 Rust 시험으로만 봤어요.
- 한글 폴더 이름이 분해형(macOS)인 작품과 NFC로 적은 규칙 저장 폴더의 이음은 시험하지 않았어요(이름을 글자 그대로 견줘요).
- 자동 화면 시험은 없어요(이 저장소에 웹 시험 도구가 없어요).
