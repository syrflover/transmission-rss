# 0014 작품 상세에서 시즌과 회차의 영상·자막 보유를 봐요

- 상태: 대기
- 출처: [작품 상세 화면](../specs/library.md#작품-상세-화면)
- 막는 티켓: [0012](0012-watch-folders-discovery.md), [0013](0013-library-screen.md)

## 작업

라이브러리에서 작품을 열면 한 번에 스크롤하는 작품 상세가 나오고, 시즌을 골라 회차마다 영상·자막 파일이 있는지 봐요.
영상 쪽과 디스크에서 찾은 파일까지가 범위이며, 할 일 카드·자막 후보·교체 승인·작품 정보는 결과 목표 3·4와 시즌 정보 연결 뒤에 붙어요.

- 머리는 표지 자리([0015](0015-work-artwork.md) 전까지 빈 표지), 작품명(폴더 이름)이에요. 원제는 모르면 두지 않아요.
  자막 제작자는 디스크에서 찾은 자막만 있으면 `제작자 알 수 없음`이에요. `제작자 변경`은 구독 제작자가 생기는 구독·자막 목표에서 붙여요.
- 시즌 타일과 휴대폰의 `시즌 변경` 시트는 명세의 선택·초점·크기 조건 그대로이고, 시즌이 하나면 숨겨요.
- 시즌 정보 칸(방영·분량·제작사·장르)과 AniList 링크는 시즌마다 AniList 항목을 연결하는 티켓(0015 다음)이 붙을 때까지 두지 않아요. 모르는 값을 다른 시즌이나 파일 상태로 채우지 않는다는 조건을 지키는 선택이에요.
- 회차 목록은 최신 화부터이고 `1화부터`로 바꿀 수 있어요. 줄은 회차·`영상 ✓`·`자막 −` 보유 표시이고, 누르면 영상 파일·자막 파일·추가 시각(미상 포함)을 이름표 달린 칸으로 펼쳐요.
  방영일은 시즌 정보와 함께 붙어요.
- 오른쪽 카드 열(휴대폰은 목록 아래 접힌 구역)에는 지금 `수집`과 `파일`만 둬요.
  `수집`은 이 작품 폴더에 받는 규칙과 규칙 상세 링크이고, `파일`은 작품 폴더 경로, 회차별 파일 대응, 회차를 확인하지 못한 파일이에요.
- 작품 폴더가 `폴더 없음`이면 머리 아래에 그 까닭을 한 줄로 두고, 마지막으로 본 기록을 보여줘요.
- 편성·할 일에서 특정 시즌·회차를 가리키는 주소로 들어오면 그 시즌을 고르고 그 회차로 스크롤해 초점을 옮겨요.

## 완료 기준

| 입력·상태 | 기대 결과 |
| --- | --- |
| 영상이 1–12화, 자막이 4·6화만 없는 시즌 | 4·6화 줄에 `영상 ✓`·`자막 −`이고 나머지는 둘 다 `✓`예요. `영상`·`자막` 라벨은 보유 여부와 관계없이 같은 크기이고, 보조기술에 보유·없음이 읽혀요. |
| 회차 줄을 누름 | 영상·자막 파일 이름과 추가 시각(첫 확인 때 있던 파일은 `미상`)이 펼쳐져요. |
| `1화부터`로 바꿈 | 1화가 맨 위예요. |
| 두 시즌이 있는 작품, 넓은 화면 | 두 타일이 보이고 선택한 타일에만 체크가 있으며, 선택 전후 타일 크기가 같아요. 시즌을 바꾸면 회차 목록이 바뀌어요. |
| 같은 작품, 휴대폰 너비 | 현재 시즌 타일과 `시즌 변경`이 보이고, 시트에서 고르면 닫혀요. Escape·배경·닫기 버튼으로 닫으면 초점이 여는 버튼으로 돌아가요. 가로 스크롤이 없어요. |
| 시즌이 하나인 작품 | 타일과 시트 버튼이 없어요. |
| `?season=2&episode=5` 같은 주소로 진입 | 시즌 2가 골라지고 5화 줄로 스크롤해 초점이 가요. |
| 규칙 두 개가 이 작품 폴더에 받는 작품 | `수집` 카드에 두 규칙이 있고 누르면 수집 화면의 그 규칙 상세로 가요. |
| 회차를 확인하지 못한 파일이 있는 작품 | `파일` 카드에 그 파일들이 까닭과 함께 보여요. 회차 줄에 임의로 붙지 않아요. |
| 작품 상세에서 뒤로 가기 | 라이브러리의 검색·필터·스크롤이 그대로예요([0013](0013-library-screen.md)). 열려 있던 시트가 남지 않아요. |
