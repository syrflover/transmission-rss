# 0089 묶음 배치에서 시즌이 다른 파일의 까닭을 맞게 적어요

- 상태: 대기
- 출처: [자막 묶음 분석과 안전한 배치 판단](../specs/subtitles.md#자막-묶음-분석과-안전한-배치-판단)
- 막는 티켓: 없음

## 작업

2026-10-07 구조 조사에서 찾았어요.
여러 파일이 든 묶음을 배치할 때, 다른 회차 파일의 이름에 적힌 시즌이 기대한 시즌과 다르면 그 파일을 배치하지 않고 까닭을 보여줘요.
기대한 시즌은 묶음 이름에 적힌 시즌이고, 없으면 작업의 시즌이에요. 그런데 까닭 문구에는 늘 작업의 시즌을 적어요(trss-jobs의 `place/package.rs`).
그래서 묶음 이름의 시즌이 작업의 시즌과 다르면 문구가 비교한 시즌과 달라요. 파일이 작업의 시즌과 같은 시즌이어도 "작업의 시즌과 달라 보여요"라고 적을 수 있어요.

## 완료 기준

- 묶음 이름의 시즌이 작업의 시즌과 다른 묶음으로 확인하는 테스트가 있어요. 문구가 실제로 견준 시즌을 적어요. 무엇과 견줬는지(묶음 이름의 시즌인지, 작업의 시즌인지)도 문구에서 알 수 있어요.
- 배치하는 파일과 배치하지 않는 파일은 지금과 같아요.
