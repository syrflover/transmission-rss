# 0021 이번 주 편성과 처음 설정 체크리스트를 보여줘요

- 상태: 대기
- 출처: [이번 주 편성](../specs/web-app.md#이번-주-편성), [처음 실행](../specs/settings.md#처음-실행)
- 막는 티켓: [0019](0019-subscription-rule-detail.md), [0020](0020-title-waiting.md)(다음 분기 제목 대기 수)

## 작업

앱의 첫 화면인 `이번 주 편성`에 구독한 방영작의 이번 주 회차를 요일별로 보여주고, 처음 실행에서는 그 자리에 `처음 설정` 체크리스트를 둬요.

- 편성: 구독 규칙에 저장된 Anissia 편성(0018)으로 이번 주 요일·시각을 정하고(`Asia/Seoul`), 회차는 이어진 시즌(0019)의 영상·자막 보유([0014](0014-work-detail-video.md))로 상태 줄을 만들어요. 카드는 표지·제목·방영 시각·회차와 상태 줄이고, 카드 전체가 작품 상세로 가는 링크예요. 시즌이 아직 이어지지 않은 구독도 카드로 보여요(`영상 대기`/`방영 전`).
- 상태 줄 중 `인증 필요`·`회차 확인 필요`·자막 받는 중은 자막 쪽(목표 3·4)이 생겨야 나오므로 이 티켓은 `영상 받음`·`영상 받는 중`·`영상 대기`·`방영 전`·`자막 받음`·`자막 대기`를 채우고, 나머지는 상태의 자리만 둬요. 강조는 명세대로 `영상 받는 중`(나중에 `인증 필요`·`회차 확인 필요`)에만 써요.
- 방영이 없는 날은 날짜·요일·`방영 없음`의 얇은 한 줄이에요. `오늘로 이동`은 오늘 줄로 스크롤하고 초점을 옮겨요. 제목 아래에 이번 주 범위·분기·기준 시각이 있어요.
- 옆 열(휴대폰은 위 한 줄 요약): 수집 상태(RSS `확인`·`다음` 시각, 수집 화면과 같은 기록에서 센 `최근 7일 추가 N개`, Transmission 받는 중·시딩 수)를 먼저, 다음 분기 구독(제목 대기 수와 편성표에서 추가하는 바로가기)을 그 아래에 둬요. 수집 상태는 지금의 `/api/collect/status`를 써요.
- 처음 설정: 감시 폴더와 채널이 하나도 없을 때 편성 자리에 `감시 폴더 등록`·`기존 설정 가져오기` 두 단계를 두고, 수집 상태·다음 분기 구독·휴대폰 요약 줄·할 일 개수 배지를 두지 않아요. 단계는 설정의 감시 폴더와 가져오기로 이어지며, 폴더를 하나 추가하거나 가져오기를 적용하면 끝나요. 건너뛰기와 되돌리기가 있고, 두 단계가 끝나거나 건너뛰면 체크리스트가 사라져요. 건너뛴 상태는 서버에 남겨 기기가 바뀌어도 같아요. 처음 실행의 기존 YAML 가져오기는 채널마다 묻지 않고 모두 추가해요.

## 완료 기준

| 입력·상태 | 기대 결과 |
| --- | --- |
| 수요일 23:30 방영 구독 둘, 금요일 하나, 나머지 요일 없음 | 수·금에 카드가 있고 나머지 날은 `방영 없음` 한 줄이에요. 카드를 누르면 작품 상세로 가요. |
| 이번 주 회차 영상이 있고 자막이 없음 | `영상 받음`·`자막 대기`이고 `자막 대기`는 강조되지 않아요. |
| 방영 시각 전 작품 | 같은 카드에 영상 `방영 전`이 조용하게 보여요. |
| 시즌이 아직 이어지지 않은 새 구독 | 카드가 보이고 표지 자리는 빈 자리예요. |
| `오늘로 이동` | 오늘 줄로 스크롤하고 초점이 옮겨져요. |
| PC 너비와 휴대폰 너비 | PC는 편성 옆 좁은 열에 수집 상태와 다음 분기 구독, 휴대폰은 위 한 줄 요약이에요. 넓은 화면은 카드가 줄바꿈되고 가로 스크롤이 없어요. |
| 감시 폴더·채널이 없는 새 설치 | 체크리스트만 보이고 수집 상태·다음 분기·요약 줄·할 일 배지가 없어요. |
| 감시 폴더 하나를 추가하고 가져오기를 건너뜀 | 체크리스트가 사라지고 이번 주 편성이 나와요. 다른 기기에서 열어도 같아요. 건너뛴 단계는 되돌릴 수 있어요. |
| 처음 실행의 기존 YAML 가져오기 | 채널마다 교체·추가·건너뛰기를 묻지 않고 모두 추가해요. |
